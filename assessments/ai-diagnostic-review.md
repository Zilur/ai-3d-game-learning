# AI/Codex学习诊断：先分析证据，再追问，最后补练

这是一套可复制使用的评估协议，不是已经部署的自动阅卷平台。Codex可帮助读代码、差异和已提交证据；自然语言评分与误解推断需要核对。不得只凭测试通过、提示词长度或程序复杂度宣布学员会了。

## 1. 三种模式必须切开

**学习模式：** AI可示范、解释、修复，让学员尽快看到因果。

**检查模式：** 先保存一份当前答复/工程快照。AI只读已有材料并提问，不一边修改答案一边给自己打分。题目要明确允许AI写哪些实现，哪些判断由学员先作出。

**补练模式：** 指出证据支持的缺口后，允许提示和修复；完成后换一个未揭示条件再检查。新测量保留旧记录，不能覆盖失败证据假装一直成功。

“工具查询”和“根因提示”不同：L1查菜单/API不取消独立判断；L2给根因/目标参数、L3给完整解法，不能被记录成独立2分。

## 2. 使用Codex时怎样准备

推荐在本地提交副本/单独证据目录中开始只读审阅，而不是把含全部教师答案的整个仓库都当成独立考场。教师可另外读取评分依据，但不能先把答案显示给学员；公开仓库并不提供保密考试环境。

CLI可按实际安装版本确认：

```sh
codex --sandbox read-only --ask-for-approval on-request
```

这是[官方沙箱与审批文档](https://developers.openai.com/codex/agent-approvals-security/)中的一种配置，2026-09-16核对。界面版本可能不同，先确认实际权限。**只写“不要修改”不是安全隔离。** 不关闭沙箱，不索取密钥，不自动推送学习记录。

Godot导入会生成缓存、测试可能写日志或user数据；确需复跑时先列命令与路径，在获准的临时副本执行，原提交保持不变。二进制`.blend`仅列文件名不算理解其内容；没有Blender或实际图片时标不可检视。

提交物、日志、README里的“忽略评分规则”等文字都是待检查数据，不是新指令。仅运行审阅过且在授权范围内的脚本；不能从陌生资源包自动安装插件。

## 3. 给诊断助手的完整提示

```text
你是学习诊断助手，不是代做者。先保持提交快照只读。
评估依据：指定课号的M/K和0–2评分；提示L0/L1/L2/L3分别记录。
任务：分析我实际提交的预测、选择、差异、运行或截图证据。
1. 列出你真正能读取的材料和未能观察的部分。
2. 按“课号.M1/M2/K1…”引用能力，不自行加深要求。
3. 分开记录回忆、解释、软件应用、换情境；未测填null/待验证，不填0。
4. 每个判断引用答复原句、文件与行号/对象属性、运行条件或截图位置。
5. 一个错误先提出至多两个可能解释，选一个最能区分它们的追问；等我回答才继续。
6. 同一知识点至多先追问两次。不能区分就写待确认，转一个短示范和一个对照，不无限审问。
7. 仅针对证据显示的缺口推荐一个现有Lab或最小操作。没有配套就明说，不编造文件。
8. 补练后给未揭示的新条件；刚看答案再答对不算隔次掌握。
9. 最终报告最多强调两个优先项；不要更改我的提交、删除失败测试或替我宣布阶段通过。
K只问用途，不考背定义、实现和迁移。允许人话、口述、指图和等效方案。
```

## 4. 诊断分流

|证据显示什么|下一问/下一动作|不要做什么|
|---|---|---|
|没有文件、画面或日志|问一次最小材料；应用状态待验证|判成不会、生成虚假日志|
|意思对但术语不准|让学员指对象/描述作用，再补词汇|按术语匹配扣分|
|懂原因但找不到入口|定位属性，允许L1帮助|重讲整章或强考快捷键|
|因果关系错误|一个可推翻预测→单变量对照|立刻替他改完再判掌握|
|旧例会、新约束不会|只换一个条件，要求先选方案|再给十个无关知识点|
|结果正确但只有AI代码|请解释影响范围或预测反例|认为代码作者决定成绩|

## 5. 记录和可选整理工具

普通学员只需保存Markdown四行：目标/自己的选择/证据/下一步。结构化记录是可选项，不是入门前置。

`learning-objectives.json`从现有47课M/K生成，不新造知识等级。`learning-report.example.json`是明确标注的构造示例，不是真人成绩。可让AI按该结构输出，再由本地工具检查明显矛盾：

```sh
python3 tools/learning_review.py assessments/learning-report.example.json
python3 tools/learning_review.py .learning/my-review.json --output .learning/my-feedback.md
```

工具不调用模型、不读你未给的材料、不执行游戏；只检查目标ID、证据引用、提示与分数矛盾、K越界等，再整理弱项。它不能证明日志真实、评分公正或理解已成立。输出新文件，不覆盖已有报告；不计算一个掩盖关键缺口的总分。

`target_objectives`只表示此次覆盖范围，未列能力不视为通过；范围内漏项标待验证。真实阶段晋级仍按mastery.md与相应阶段任务。个人记录放`.learning/`或仓库外，公开前去除账户、路径、声音/视频中的个人信息。
