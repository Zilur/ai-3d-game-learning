# 训练题：先作答，再看答案

每题先写结论、理由和验证方法。P用于当堂预测，T用于隔次迁移。题目不按是否提到某个关键词机械评分。

答案在单独的 [answer-key.md](answer-key.md)。AI可以追问，但首次作答前不能代答。

## C01 · 坐标轴 Axis

**C01-P｜预测：** 转动相机后，世界 +X 会跟着相机改变吗？

**C01-T｜迁移：** 把 Blender 模型直接绕 X 旋转 90° 修复导入，为什么要先查导入转换？

验证任务：旋转观察相机，再沿世界 X 移动物体。

## C02 · 位置、旋转、缩放 Transform

**C02-P｜预测：** 宽 2 的网格 Scale X=3，在无父级缩放时宽多少？

**C02-T｜迁移：** 门的可见几何移动了，但 Origin 留在原处，可能做了哪种操作？

验证任务：在 Blender 分别移动 Object 与 Edit Mode 全部顶点。

## C03 · 父空间、自身空间、世界空间

**C03-P｜预测：** 父节点只平移到(5,0,0)，子节点 position=(2,0,0)，世界位置是多少？

**C03-T｜迁移：** 父节点再旋转90°后，还能逐项相加位置吗？

验证任务：父节点绕 Y 转 90°；比较 parent X、self X、world X 三种移动。

## C04 · 原点 Origin 与操作支点 Pivot

**C04-P｜预测：** 门绕中心打转，优先改动画角度还是轴与网格的相对位置？

**C04-T｜迁移：** 风车正确转动但门不正确，能否认定所有中心 Pivot 都错？

验证任务：保持门关闭时的位置相同，只改变中心轴/铰链轴。

## C05 · 场景、节点、实例 Scene / Node / Instance

**C05-P｜预测：** 同一颗星星需要复用5次，复制整份脚本还是实例化场景？

**C05-T｜迁移：** 只想换角色外形，应该先替换哪个部分？

验证任务：复制一份星星场景实例，改位置后运行。

## C06 · 可见网格与碰撞 Mesh / Collision

**C06-P｜预测：** 隐藏墙 Mesh，保留碰撞体，人能通过吗？

**C06-T｜迁移：** 做树叶时是否每片叶子都要精确碰撞？

验证任务：先隐藏墙 Mesh，再禁用墙 Shape，对比能否走过。

## C07 · 碰撞层与检测掩码 Layer / Mask

**C07-P｜预测：** 玩家在第2层；Area 想检测它，至少该在 Mask 勾哪层？

**C07-T｜迁移：** Mask 正确但无事件，还要查什么？

验证任务：星星 mask 从2改为1，比较是否收到玩家 body_entered。

## C08 · 速度、位移与时间步 Velocity / Delta

**C08-P｜预测：** speed=4 时写 velocity.x=4*delta 再 move_and_slide，哪里错？

**C08-T｜迁移：** 如果直接改 position += velocity，应如何按秒移动？

验证任务：在30/60物理tick下比较同一秒的移动距离。

## C09 · 重力、落地与跳跃 Ground / Jump

**C09-P｜预测：** 重力变大而起跳速度不变，理想情况下跳得更高还是更低？

**C09-T｜迁移：** 斜坡能走，台阶却卡住，为什么不能声称引擎自动支持爬楼梯？

验证任务：固定 jump_speed，单独增加 gravity；对比最高点和滞空。

## C10 · 相机视野与相机碰撞 Camera / FOV

**C10-P｜预测：** 镜头变广角后，角色实际碰撞体会变小吗？

**C10-T｜迁移：** 相机绕玩家旋转后，W 仍沿原世界方向，优先查哪里？

验证任务：固定距离改FOV，再固定FOV改距离；靠近墙测SpringArm。

## C11 · 几何、法线与倒角 Mesh / Normal / Bevel

**C11-P｜预测：** 平滑后轮廓仍尖，为什么？

**C11-T｜迁移：** 模型背面看不见，能否只用双面材质掩盖？

验证任务：给同一立方体分别平滑着色和实际倒角，观察轮廓。

## C12 · 基础色、金属与粗糙度 PBR

**C12-P｜预测：** 塑料很亮，应该一定把 Metallic 调到1吗？

**C12-T｜迁移：** 旧铁剑的裸金属与锈斑应如何分开考虑？

验证任务：固定灯光相机，对照两个球；一次只拖一项。

## C13 · 自发光、光晕与照明 Emission / Glow / Light

**C13-P｜预测：** 星星亮了但地板没亮，一定是程序错吗？

**C13-T｜迁移：** 在不同渲染器里同样参数为何不能保证同样画面？

验证任务：材质实验里先调Emission，再单独开OmniLight。

## C14 · UV 与纹理 Texture

**C14-P｜预测：** 棋盘格被拉成长条，先增贴图分辨率吗？

**C14-T｜迁移：** 两面墙贴图尺寸相同但清晰度不同，查什么？

验证任务：给立方体用棋盘格；故意拉长一组UV，对比格子。

## C15 · 导出、导入与资源所有权 glTF / Reimport

**C15-P｜预测：** 重导入后手工改的材质丢失，说明什么？

**C15-T｜迁移：** 能否把静态资产的Apply All Transforms流程直接用于已绑定、带动画的角色？

验证任务：修改源星星颜色再导出，检查Godot包装场景里的碰撞仍在。

## C16 · 事件与状态 Signal / State

**C16-P｜预测：** 把UI文字当作星星数量的唯一存储合理吗？

**C16-T｜迁移：** 再加钥匙和门，应该让所有对象互相改UI吗？

验证任务：同一帧连续触发两次 try_collect，计数仍只能加1。

## C17 · 共享资源与独立实例 Resource

**C17-P｜预测：** 只改一球材质另一个也变了，优先怀疑什么？

**C17-T｜迁移：** 生成1000树时每棵都复制全套大纹理是好主意吗？

验证任务：两个球共用材质，改一个变两个；再Make Unique对照。

## C18 · 反馈与可读性 Feedback

**C18-P｜预测：** 静音后完全不知道是否拾取，缺什么？

**C18-T｜迁移：** 用户对闪烁敏感时如何保留成功感？

验证任务：分别静音、隐藏计数、调低对比度测试拾取反馈。

## C19 · 帧预算与测量 Frame Time

**C19-P｜预测：** 平均60FPS就保证每帧都在16.7ms内吗？

## C20 · 复现、最小改动与回滚 Debug / Git

## C21 · 骨骼、蒙皮与动画状态

## C22 · 模块化、网格吸附与尺度
