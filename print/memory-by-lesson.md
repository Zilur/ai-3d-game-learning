# 逐课记忆索引：只复习当前已经学过的部分

与47课作者源同步。优先随手卡见[核心卡](essential-memory.md)；这不是要求背完47课。每课先遮住规则，回答自测；K只认识用途。

<a id="a01"></a>
## A01｜美术对话：把唯美、卡通说具体

必须掌握的限定能力：
- 用轮廓、比例、色彩、光照、表面五类词描述偏好。
- 给出保留项、排除项和一个可检查的视觉目标。

必记/用途提示：
- 感受要落到可见特征。
- 喜欢与不喜欢都要描述。
- 风格规则比堆艺术家名字更可执行。
- 本项目先固定“温暖、风格化、低写实”的方向，再用实际参考细化，不靠抽卡决定画风。

**遮住上面后自问：** 把所有材质变鲜艳就一定是卡通吗？
**不会时：** 回[A01学生稿](../curriculum/lessons/A01.md)，只做相应对照；不要背教师答案。

## A02｜空间入门：位置、旋转、缩放

必须掌握的限定能力：
- 辨认世界坐标轴，区分屏幕方向和世界方向。
- 选择Position/Rotation/Scale完成目标并恢复初值。

必记/用途提示：
- 先问改位置、朝向还是大小。
- Scale是倍率，不是米数。
- 屏幕方向不等于世界方向。

**遮住上面后自问：** 方块底部和顶部一起向上，厚度保持。只改位置、旋转、缩放中的哪类？给一个能与拉长区分的观察。
**不会时：** 回[A02学生稿](../curriculum/lessons/A02.md)，只做相应对照；不要背教师答案。

## A04｜看得见、挡得住、能检测是三回事

## A05｜走与跑：输入、速度和时间

必须掌握的限定能力：
- 用输入动作表达意图，选择走跑参数。
- 区分速度与位移，检查时间步误用和斜向增速。

必记/用途提示：
- 先看每秒还是每帧。
- 不要无条件到处乘delta。
- 测同一时长再比速度。

**遮住上面后自问：** 在无遮挡平面、无加速的教学条件下，走速4、跑速7，同测2秒。预期谁更远？为什么改物理采样次数不应让总距离直接翻倍？

<a id="a06"></a>
## A06｜跳跃：调手感而不是背公式

必须掌握的限定能力：
- 固定一项参数比较起跳速度、重力对轨迹的影响。
- 用落地条件限制跳跃，验收落地、边缘和重复输入。

必记/用途提示：
- 一次只改一项手感参数。
- 接近地面不等于已经落地。
- 不靠删除功能来排错。

**遮住上面后自问：** 使用恒定重力参考跳跃，起跳速度不变。只增大向下重力时，最高点和回落时间怎样变化？说明一个需保持的比较条件。
**不会时：** 回[A06学生稿](../curriculum/lessons/A06.md)，只做相应对照；不要背教师答案。

## A07｜相对谁：父空间、自身方向和门轴

必须掌握的限定能力：
- 区分父相对位置、物体自身方向和世界方向。
- 保持关闭时门板位置不变，只改变支点比较旋转。

必记/用途提示：
- 位置先说明相对谁。
- 临时Pivot不等于资产Origin。
- 判断支点看哪个点该固定。

**遮住上面后自问：** 父节点先转90度，子物体有非零偏移，自身又转45度且缩放为1。沿世界、父、自身的+X操作时方向应全相同吗？只用轴箭头预测，不计算坐标。

## A08｜固定/有限镜头：构图舒服，移动清楚

必须掌握的限定能力：
- 选择固定镜头的位置、角度与投影/视野基线，并用实际玩家画面说明取舍。
- 让地面移动在固定镜头下方向一致；需要分区切镜时检查进入、退出和边界稳定。

必记/用途提示：
- Camera先决定玩家实际会看到什么。
- 固定镜头仍要实走验证移动方向与落点。
- 不把“更会动的相机”自动当成更高级。

**遮住上面后自问：** 固定视角游戏是否必须再加鼠标自由转镜头，才算真正3D？

## B11｜性能入门：先测，再判断要不要优化

必须掌握的限定能力：

## C05｜复用与资源：共享什么、独立什么

必须掌握的限定能力：
- 区分共享材质/配置与独立的运行状态。
- 限定修改影响范围并验收。

必记/用途提示：
