# 实战与AI协作随手卡

适合打印。不是额外考试；每课只用与当前任务有关的几项。

## 做之前

- [ ] 我知道本课要解决庭院里的哪个实际问题。
- [ ] 我能先给一个预测，不让AI先把答案说完。
- [ ] 我写清了允许改变和必须保持的对象。
- [ ] 当前版本、材料与工具是否真能访问，已经核对。

## AI做初稿，我作选择

- [ ] AI的任务足够小，能说明交付什么和怎么恢复。
- [ ] 没有实际连接/执行，就不接受“已经改好了”的说法。
- [ ] 方向不对给参考；结构不对局部修；接近目标先亲调一项。
- [ ] 参数先记原值，固定机位/路线，一次只改一个。
- [ ] 先看大形、主次与游戏距离，再决定是否值得加细节。

## 做之后

- [ ] 我能说出改了什么、看到什么、为什么接受或撤销。
- [ ] 不只看新效果，还验证一条相关的旧功能。
- [ ] 证据不足就记待验证，模拟/代码生成不等于真机通过。
- [ ] 关键概念隔次换对象再查；K知道用途即可，不背百科。
- [ ] 有AI根因提示如实记练习，允许查菜单/API。

## 必须分开的几对东西

可见外观与物理/触发；节点实例与共享资源；速度与位移；自发光与周围照明；源文件与导入结果；AI建议与实际证据；课程已写与学员已掌握。

## 最少写这三句

这次我解决：________________
AI负责________；我亲自选择/调整________。
我用________证明目标满足；________旧功能没坏；恢复方式________。

主线：学一点 → 小实验 → AI局部初稿 → 自己选择/亲调 → 回到庭院 → 验收。高级无需求不加，资产少而可复用。
