# 核心随手卡：记判断，不背软件百科

使用：先遮住“必记规则”，看左栏自问；再核对规则；仍不确定就做一次Lab对照。只复习已学部分。会查询菜单/API不算记忆失败。逐课版见[记忆索引](memory-by-lesson.md)。

## A组学完后先记六条

|自问|必记规则|对应课|
|---|---|---|
|我到底想要什么？|给AI目标、参考中的具体特征、不能改变项；“更漂亮”不是完整需求|A01|
|我选的是谁，相对谁？|先看对象/父子关系和坐标空间，再改位置旋转缩放|A02/A03/A07|
|为什么看不见还挡路？|外观、物理阻挡、重叠检测是不同职责|A04|
|谁看谁？|Layer说明自己属于哪些类，Mask说明检测者关注哪些类|A04|
|角色怎么走、怎么落？|速度是单位时间的位移；跳跃初速和重力共同影响腾空，改一个看一个|A05/A06|
|固定视角要验什么？|角色、路径与落点在实际机位清楚；固定角度不等于所有事件反馈都禁止|A08|

## B组再记六条

|自问|必记规则|对应课|
|---|---|---|
|漂亮还是拥挤？|先大形、主次和留白，再局部细节；缩到游戏尺寸再判断|B01/B03/B10|
|只改一件会影响谁？|先检查共享引用；需要变体时只独立该独立的资源|B04|
|换模型会改坏玩法吗？|源视觉资产与游戏功能包装分开；重导入也要验证尺寸、朝向和功能|B02/B05|
|播了特效就算成功吗？|事件要满足条件；同一奖励只能接受一次，表现不是状态的权威来源|B06/B07|
|重开清干净了吗？|UI读真实状态；完成、重开后从第一步重新验证|B08|
|AI说好了就信吗？|区分建议/执行/验证；先看范围与证据，同条件比较，局部改、可回退|B11/B12|

## 进入生产后加四个习惯

先拿代理资产玩通，再用小样验证重导入、风格和成本；不要整图一次换皮。

保留优秀基底，只改实际机位可见且有收益的比例、部件、配色和材质；同一套材质数值不等于统一风格。

性能、目标设备、许可证和角色/动作兼容要早试；最终再完整验收，不把风险全部推到项目最后。

方向偏了补参考，单项效果接近了亲调，结构错了局部修，原因不明先对照；AI可执行，人负责选择和认可证据。

**牢记不等于精通实现。** 不背位运算、矩阵推导、Shader数学、完整绑定、全部修改器参数。当前任务需要时，才查具体方法。
