# 必须牢记：AI 时代 3D 开发随身卡

打印前：只打印当前阶段；本文件不含答案、长代码或宽表格。建议A4纵向，使用支持Markdown打印的编辑器。实际分页取决于字体和渲染器，不承诺固定页数。

不是要求背API。遮住解释时，能说出要点、识别反例并在软件里验证，才算记住。

## 初级：先做得对

**C01 坐标轴 Axis**

先辨认轴、坐标空间和单位；本课程 Godot 为 Y 向上，Blender 为 Z 向上。

不要误记：屏幕右方不是永远的世界 +X。

**C02 位置、旋转、缩放 Transform**

Scale 是相对倍数，不是绝对米数；对象变换与编辑网格是不同操作。

不要误记：Scale=1 不代表模型宽 1 米。

**C03 父空间、自身空间、世界空间**

position 通常相对父节点；自身轴移动需要变换方向；global_position 是世界位置。

不要误记：切换 Local Gizmo 不会把 Inspector 的 position 自动改成世界坐标。

**C04 原点 Origin 与操作支点 Pivot**

Blender 对象 Origin 与当前工具 Pivot 不同；Godot 可用父 Node3D 当门轴。

不要误记：把 Blender 工具 Pivot 改到3D光标，不等于改好导出门轴。

**C05 场景、节点、实例 Scene / Node / Instance**

节点负责职责，场景是一组可复用节点；实例不是截图。

不要误记：删掉视觉节点不等于删掉角色功能。

**C06 可见网格与碰撞 Mesh / Collision**

看得见不保证挡得住；Area 检测重叠，StaticBody 用于静态阻挡。

不要误记：法线贴图、渲染细节不自动成为物理几何。

**C07 碰撞层与检测掩码 Layer / Mask**

Layer 是我属于哪类，Mask 是这次查询要看哪些类。

不要误记：不能把“两个物体所有勾选必须完全相同”当规则。

**C08 速度、位移与时间步 Velocity / Delta**

速度是每秒多少；加速度更新速度要乘时间；move_and_slide 不再给速度乘 delta。

不要误记：凡是移动都乘 delta 是危险口诀。

**C09 重力、落地与跳跃 Ground / Jump**

跳跃按落地状态门控，重力持续更新竖直速度；落地信息来自物理移动。

不要误记：看到脚在地面附近不等于 is_on_floor 已成立。

**C10 相机视野与相机碰撞 Camera / FOV**

FOV 改变透视视野，不改变世界尺寸；镜头本身也要检测障碍。

不要误记：缩小FOV与把相机移近不是同一个变换。

**C11 几何、法线与倒角 Mesh / Normal / Bevel**

法线影响表面着色方向；倒角改几何；平滑着色不等于加细节。

不要误记：Shade Smooth 不会把立方体轮廓变成圆角。

**C12 基础色、金属与粗糙度 PBR**

Roughness 调反射清晰度；Metallic 区分金属/非金属响应，不是亮度旋钮。

不要误记：锈蚀铁不是整个物体一律Metallic=1；锈层通常按非金属处理。

**C13 自发光、光晕与照明 Emission / Glow / Light**

表面发亮、屏幕光晕、照亮周围是三种不同现象。

不要误记：仅调 Emission 不保证地板受光，也不保证有Glow。

**C15 导出、导入与资源所有权 glTF / Reimport**

源资产修改后重新导入；不要把易被重导入覆盖的生成文件当唯一编辑源。

不要误记：Blender任意节点材质都能原样导出是错误假设。

**C16 事件与状态 Signal / State**

事件表示发生了什么；状态表示现在是什么；拾取必须只计一次。

不要误记：queue_free 不等于立即从所有回调消失。

**C18 反馈与可读性 Feedback**

交互成功要能被感知；不要只靠颜色、声音或大段粒子表达。

不要误记：更亮、更多闪烁不等于更清楚。

**C19 帧预算与测量 Frame Time**

60FPS对应约16.7ms间隔预算；1000/FPS不等于GPU耗时。

不要误记：三角形少或平均FPS高，不代表没有卡顿。

**C20 复现、最小改动与回滚 Debug / Git**

先复现并保留证据，再做单变量修改；AI说修好了不算验收。

不要误记：一次改20处即使好了，也不知道根因。

**C26 目标设备与资产来源**

目标硬件、来源、使用条件和可追溯性都要在制作前确认。

不要误记：下载免费或AI生成，不等于可以任意商用再分发。

## 中级：做得可复用

**C14 UV 与纹理 Texture**

UV 决定贴图落在哪里；贴图分辨率、UV分配和过滤共同影响清晰度。

不要误记：一味升到4K并不能修复拉伸的UV。

**C17 共享资源与独立实例 Resource**

场景实例可独立，但其中材质等资源可能共享。

不要误记：实例化场景并不保证所有嵌套资源深拷贝。

**C21 骨骼、蒙皮与动画状态**

骨骼驱动形变，蒙皮权重分配影响；状态切换与动画混合不是同一件事。

不要误记：换模型不保证骨架、朝向、动画名称都兼容。

**C22 模块化、网格吸附与尺度**

可拼装资产需要一致尺寸、原点和网格规则。

不要误记：好看的单个房子未必能模块化拼接。

**C23 导航与物理路径 Navigation**

导航给可走路径，物理决定实际阻挡；动态障碍需对应更新策略。

不要误记：烘焙出路径不代表角色永不穿墙或不卡住。

**C24 存档、设置与数据版本**

存档是稳定的数据契约，应考虑缺失、损坏和版本迁移。

不要误记：把运行时节点整棵写进去不是通用的存档方案。

**C25 光照、环境与渲染器**

先定目标平台和渲染器，再选画面方案；实时光与烘焙光有不同约束。

不要误记：更强GI不是所有设备都适合的默认选项。

## 高级：做得可测量、可扩展

**C27 着色器与可控参数 Shader**

Shader负责渲染计算，不自动修改碰撞；先做一个可解释效果。

不要误记：顶点被Shader推开后，玩家就会按新表面碰撞是错误假设。

**C28 复杂旋转与插值 Quaternion / Basis**

知道旋转组合与插值的边界；查API，不必背四元数展开式。

不要误记：逐分量线性插值欧拉角并不总是走预期最短旋转。

**C29 实例化与剔除 MultiMesh / Culling**

大量重复物体可合批，但剔除粒度、材质和交互需求仍要权衡。

不要误记：普通场景实例不等于一次绘制；一个超大MultiMesh也不保证最优。

**C30 LOD、遮挡与资源流送**

LOD降细节，遮挡剔除不画看不见的，流送管理资源驻留。

不要误记：三者不是同一优化，也不是打开就无代价。

**C32 性能预算与回归实验**

优化必须固定测试条件，有基线、分布、可重复路径及画面正确性检查。

不要误记：单次最快FPS截图不是优化证据。

## 可选高级专题

C31 网络权威：谁能决定状态、如何应对同时请求和重连。单机主线不要求实现网络同步。

## 随身排错顺序

复现 → 记录版本/现象/预期 → 看节点与资源 → 一次只改一项 → 原案例验证 → 新案例回归 → 看diff → 提交。

不要上传密钥；不要把生成完成当成验收；不要把网页演示当成Godot真实物理或性能。
