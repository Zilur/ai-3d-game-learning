# 概念地图：按阶段决定深度

“必须掌握”=能预测、操作、诊断并在新情境应用；“应该了解”=说出用途、风险及何时查资料。
`—`只是该阶段未引入，不是第三种知识等级。进入更高阶段不抹掉低阶段的必修能力。
C31 是可选高级专题：主线只要求了解，选择网络项目后才提升为必须掌握。
题库中每个 Cxx 都有 P（预测）和 T（迁移）两题。必修概念还必须提交实操证据。

## 每个概念的反例与实验

### C01 · 坐标轴 Axis

牢记：先辨认轴、坐标空间和单位；本课程 Godot 为 Y 向上，Blender 为 Z 向上。

容易误判：屏幕右方不是永远的世界 +X。

实验：旋转观察相机，再沿世界 X 移动物体。

关联训练：C01-P、C01-T。

### C02 · 位置、旋转、缩放 Transform

牢记：Scale 是相对倍数，不是绝对米数；对象变换与编辑网格是不同操作。

容易误判：Scale=1 不代表模型宽 1 米。

实验：在 Blender 分别移动 Object 与 Edit Mode 全部顶点。

关联训练：C02-P、C02-T。

### C03 · 父空间、自身空间、世界空间

牢记：position 通常相对父节点；自身轴移动需要变换方向；global_position 是世界位置。

容易误判：切换 Local Gizmo 不会把 Inspector 的 position 自动改成世界坐标。

实验：父节点绕 Y 转 90°；比较 parent X、self X、world X 三种移动。

关联训练：C03-P、C03-T。

### C04 · 原点 Origin 与操作支点 Pivot

牢记：Blender 对象 Origin 与当前工具 Pivot 不同；Godot 可用父 Node3D 当门轴。

容易误判：把 Blender 工具 Pivot 改到3D光标，不等于改好导出门轴。

实验：保持门关闭时的位置相同，只改变中心轴/铰链轴。

关联训练：C04-P、C04-T。

### C05 · 场景、节点、实例 Scene / Node / Instance

牢记：节点负责职责，场景是一组可复用节点；实例不是截图。

容易误判：删掉视觉节点不等于删掉角色功能。

实验：复制一份星星场景实例，改位置后运行。

关联训练：C05-P、C05-T。

### C06 · 可见网格与碰撞 Mesh / Collision

牢记：看得见不保证挡得住；Area 检测重叠，StaticBody 用于静态阻挡。

容易误判：法线贴图、渲染细节不自动成为物理几何。

实验：先隐藏墙 Mesh，再禁用墙 Shape，对比能否走过。

关联训练：C06-P、C06-T。

### C07 · 碰撞层与检测掩码 Layer / Mask

牢记：Layer 是我属于哪类，Mask 是这次查询要看哪些类。

容易误判：不能把“两个物体所有勾选必须完全相同”当规则。

实验：星星 mask 从2改为1，比较是否收到玩家 body_entered。

关联训练：C07-P、C07-T。

### C08 · 速度、位移与时间步 Velocity / Delta

牢记：速度是每秒多少；加速度更新速度要乘时间；move_and_slide 不再给速度乘 delta。

容易误判：凡是移动都乘 delta 是危险口诀。

实验：在30/60物理tick下比较同一秒的移动距离。

关联训练：C08-P、C08-T。

### C09 · 重力、落地与跳跃 Ground / Jump

牢记：跳跃按落地状态门控，重力持续更新竖直速度；落地信息来自物理移动。

容易误判：看到脚在地面附近不等于 is_on_floor 已成立。

实验：固定 jump_speed，单独增加 gravity；对比最高点和滞空。

关联训练：C09-P、C09-T。

### C10 · 相机视野与相机碰撞 Camera / FOV

牢记：FOV 改变透视视野，不改变世界尺寸；镜头本身也要检测障碍。

容易误判：缩小FOV与把相机移近不是同一个变换。

实验：固定距离改FOV，再固定FOV改距离；靠近墙测SpringArm。

关联训练：C10-P、C10-T。

### C11 · 几何、法线与倒角 Mesh / Normal / Bevel

牢记：法线影响表面着色方向；倒角改几何；平滑着色不等于加细节。

容易误判：Shade Smooth 不会把立方体轮廓变成圆角。

实验：给同一立方体分别平滑着色和实际倒角，观察轮廓。

关联训练：C11-P、C11-T。

### C12 · 基础色、金属与粗糙度 PBR

牢记：Roughness 调反射清晰度；Metallic 区分金属/非金属响应，不是亮度旋钮。

容易误判：锈蚀铁不是整个物体一律Metallic=1；锈层通常按非金属处理。

实验：固定灯光相机，对照两个球；一次只拖一项。

关联训练：C12-P、C12-T。

### C13 · 自发光、光晕与照明 Emission / Glow / Light

牢记：表面发亮、屏幕光晕、照亮周围是三种不同现象。

容易误判：仅调 Emission 不保证地板受光，也不保证有Glow。

实验：材质实验里先调Emission，再单独开OmniLight。

关联训练：C13-P、C13-T。

### C14 · UV 与纹理 Texture

牢记：UV 决定贴图落在哪里；贴图分辨率、UV分配和过滤共同影响清晰度。

容易误判：一味升到4K并不能修复拉伸的UV。

实验：给立方体用棋盘格；故意拉长一组UV，对比格子。

关联训练：C14-P、C14-T。

### C15 · 导出、导入与资源所有权 glTF / Reimport

牢记：源资产修改后重新导入；不要把易被重导入覆盖的生成文件当唯一编辑源。

容易误判：Blender任意节点材质都能原样导出是错误假设。

实验：修改源星星颜色再导出，检查Godot包装场景里的碰撞仍在。

关联训练：C15-P、C15-T。

### C16 · 事件与状态 Signal / State

牢记：事件表示发生了什么；状态表示现在是什么；拾取必须只计一次。

容易误判：queue_free 不等于立即从所有回调消失。

实验：同一帧连续触发两次 try_collect，计数仍只能加1。

关联训练：C16-P、C16-T。

### C17 · 共享资源与独立实例 Resource

牢记：场景实例可独立，但其中材质等资源可能共享。

容易误判：实例化场景并不保证所有嵌套资源深拷贝。

实验：两个球共用材质，改一个变两个；再Make Unique对照。

关联训练：C17-P、C17-T。

### C18 · 反馈与可读性 Feedback

牢记：交互成功要能被感知；不要只靠颜色、声音或大段粒子表达。

容易误判：更亮、更多闪烁不等于更清楚。

实验：分别静音、隐藏计数、调低对比度测试拾取反馈。

关联训练：C18-P、C18-T。

### C19 · 帧预算与测量 Frame Time

牢记：60FPS对应约16.7ms间隔预算；1000/FPS不等于GPU耗时。

容易误判：三角形少或平均FPS高，不代表没有卡顿。

实验：同路线同分辨率，分别开关阴影，记录帧时间分布。

关联训练：C19-P、C19-T。

### C20 · 复现、最小改动与回滚 Debug / Git

牢记：先复现并保留证据，再做单变量修改；AI说修好了不算验收。

容易误判：一次改20处即使好了，也不知道根因。

实验：故障分支只改Mask；写步骤、现象、预期和恢复方式。

关联训练：C20-P、C20-T。

### C21 · 骨骼、蒙皮与动画状态

牢记：骨骼驱动形变，蒙皮权重分配影响；状态切换与动画混合不是同一件事。

容易误判：换模型不保证骨架、朝向、动画名称都兼容。

实验：切换Idle/Walk/Jump，观察脚滑和落地过渡。

关联训练：C21-P、C21-T。

### C22 · 模块化、网格吸附与尺度

牢记：可拼装资产需要一致尺寸、原点和网格规则。

容易误判：好看的单个房子未必能模块化拼接。

实验：用同一墙片拼直角和长廊，检查缝隙及碰撞。

关联训练：C22-P、C22-T。

### C23 · 导航与物理路径 Navigation

牢记：导航给可走路径，物理决定实际阻挡；动态障碍需对应更新策略。

容易误判：烘焙出路径不代表角色永不穿墙或不卡住。

实验：增设墙后比较路径显示与实际角色运动。

关联训练：C23-P、C23-T。

### C24 · 存档、设置与数据版本

牢记：存档是稳定的数据契约，应考虑缺失、损坏和版本迁移。

容易误判：把运行时节点整棵写进去不是通用的存档方案。

实验：保存数量后增加新字段，再载入旧存档。

关联训练：C24-P、C24-T。

### C25 · 光照、环境与渲染器

牢记：先定目标平台和渲染器，再选画面方案；实时光与烘焙光有不同约束。

容易误判：更强GI不是所有设备都适合的默认选项。

实验：固定场景对照烘焙/实时方案，记录动态物体表现和成本。

关联训练：C25-P、C25-T。

### C26 · 目标设备与资产来源

牢记：目标硬件、来源、使用条件和可追溯性都要在制作前确认。

容易误判：下载免费或AI生成，不等于可以任意商用再分发。

实验：给每个资源写来源与用途；在目标设备上验证最低需求。

关联训练：C26-P、C26-T。

### C27 · 着色器与可控参数 Shader

牢记：Shader负责渲染计算，不自动修改碰撞；先做一个可解释效果。

容易误判：顶点被Shader推开后，玩家就会按新表面碰撞是错误假设。

实验：做幅度可调的顶点摆动；同时显示静态碰撞体。

关联训练：C27-P、C27-T。

### C28 · 复杂旋转与插值 Quaternion / Basis

牢记：知道旋转组合与插值的边界；查API，不必背四元数展开式。

容易误判：逐分量线性插值欧拉角并不总是走预期最短旋转。

实验：对比从179°到-179°的两种插值轨迹。

关联训练：C28-P、C28-T。

### C29 · 实例化与剔除 MultiMesh / Culling

牢记：大量重复物体可合批，但剔除粒度、材质和交互需求仍要权衡。

容易误判：普通场景实例不等于一次绘制；一个超大MultiMesh也不保证最优。

实验：比较普通节点与分块MultiMesh；移动镜头记录实际成本。

关联训练：C29-P、C29-T。

### C30 · LOD、遮挡与资源流送

牢记：LOD降细节，遮挡剔除不画看不见的，流送管理资源驻留。

容易误判：三者不是同一优化，也不是打开就无代价。

实验：同一路线分别改变LOD、遮挡和加载边界，记录突变与尖峰。

关联训练：C30-P、C30-T。

### C31 · 网络权威与延迟 Multiplayer

牢记：可选专题：共享状态要确定谁有权决定，以及延迟/重连怎样处理。

容易误判：单机触发拾取再广播，不能自动保证多人唯一归属。

实验：纸面模拟两客户端同时拾同一星星，由一个权威裁定。

关联训练：C31-P、C31-T。

### C32 · 性能预算与回归实验

牢记：优化必须固定测试条件，有基线、分布、可重复路径及画面正确性检查。

容易误判：单次最快FPS截图不是优化证据。

实验：同机器同设置重复跑路线，对照中位数、慢帧、CPU/GPU及视觉损失。

关联训练：C32-P、C32-T。
