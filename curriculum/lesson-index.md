# 课程索引：先课件，后素材与真实工程

45份独立生成课件：初级17（B01拆A/B）、中级12、高级6、审美/美术8、动作复用2。编号保留连续性；不要求全部按表学完。
每课都有正文、实验、深度、题目、评分反馈与来源。正文完成不等于课堂生成或试教完成。
