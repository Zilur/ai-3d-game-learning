# 预览与亲调：先看对地方，再决定改什么

本页是按需速查，不新增考试。基本循环：选对象 → 读原值 → 固定观察条件 → 只改一项 → 比较 → 保存到来源 → 重新打开/运行。只有最后一步也符合预期，才说明选定结果能延续。

## 1. Godot：区分你在看和改的对象

|你正在做什么|先看哪里|必须留意|
|---|---|---|
|编辑布局|Local场景树中实际选中的节点及Inspector|父节点整体移动和Visual子节点偏移不是同一件事|
|检查运行时|运行后Scene面板的Remote树和Inspector|这里检查的是运行实例；不能据此假定来源文件已保存|
|跑独立练习|打开目标场景，用Run Current Scene（通常F6）|Run Project（通常F5）是主场景；快捷键可重映射，不考记忆|
|判断墙/检测范围|运行中的Visible Collision Shapes和当前对象条件|外观正常不证明物理正常；形状可见也不证明对象过滤正确|
|确认设计值留下了|停止运行后核对本地场景/资源或生成它的配置；保存再运行|脚本初始化可能重新赋值，要问谁拥有这个值；不要盲目到处写同一个数|

运行中调值可帮助试手感，但确认后应把所选值写回正确的编辑来源，并重新运行验证。不要把“按了保存”视作对任意运行时状态的存档保证。动态生成节点可能需要改脚本暴露参数/资源，不一定有一个本地节点可直接照抄。

已有参考场景的路径和运行方式见[工程说明](../game/README.md)。这是参考，不代表每堂新课的起点都已打包。

## 2. Blender：预览模式也属于实验条件

|模式/位置|优先用来判断|不应据此保证|
|---|---|---|
|Solid实体视图|形状、轮廓、比例、选中对象与编辑模式|最终材质和灯光已经正确|
|Material Preview材质预览|在预览光照下比较材质；检查Scene Lights/Scene World选择|看到的环境与实际场景灯光或Godot一致|
|Rendered渲染预览|所选渲染器和当前场景条件下的表现|目标游戏设备上能得到相同观感和成本|
|相机视图与约定游戏距离|构图、可辨性、小细节是否值得|静帧已证明镜头移动舒适|
|Object/Edit Mode及Outliner|究竟改的是对象变换还是内部网格|改了全部顶点就等于原点也移动了|

材质预览可使用HDRI预览环境；场景灯光和世界环境选项会影响所见条件。遇到“材质预览好看、渲染/游戏不一样”，先核对条件再改模型，不应靠反复加亮补偿所有差异。[依据：Blender Viewport Shading](https://docs.blender.org/manual/en/latest/editors/3dview/display/shading.html)

保存修改后的可编辑源，再按资产流程输出交换文件；Godot重导入后重新检查。保存.blend不是自动更新所有游戏文件，也不意味着复杂节点一定能导出。[对应课程](lessons/B09.md)

## 3. 常用亲调只记“入口—观察—停手依据”

|用途|AI适合先做|你更值得亲自试|检查范围|
|---|---|---|---|
|移动/跳跃|准备控制器和少量暴露参数|一次只选走速或起跳值，走同一路线|不同时改地图尺度来补偿|
|镜头|搭跟随与避障初稿|距离、FOV、灵敏度分别比较|近墙、落点、鼠标释放；不强忍不适|
|材质|设置独立/共享关系与初稿|颜色或粗糙度选一项|相机灯光固定；其他对象没串改|
|光照|按实际参考给主光初稿|方向或能量选一项|看目标和路径，不只看整图亮度|
|基底改造|重复布置、候选修改和恢复方案|比例、间隙、少量倒角|在游戏距离检查；原点和功能不丢|
|动作|接入兼容片段与测试记录|速度、过渡或接触时机分别试|运行游戏检验命中与恢复，不只看动画预览|

这些不是“人必须拖滑杆才算学”。也可用数字输入、键盘，或让AI执行你已选定的值。评分看判断和证据，不看手指操作速度。

## 4. 一条可以直接发送的定位指令

```text
我现在不要求美化或重写。下面会提供当前图、选中对象和实际软件版本。
请先确认：我在哪个预览/运行环境，选中了哪个对象，哪个文件或配置拥有待修改值。
只指出一个相关入口及其作用，说明应观察什么和怎样恢复；不先替我选择最终数值。
我选值后再协助执行/核对。没有执行记录就写未执行；改完应从来源保存并重新运行验证。
```

## 5. 最小留证

同条件的前后图足够证明许多静态视觉变化；运动、一次性计数、重复命中和恢复需要短过程或相关状态记录。不是每次都录长视频，更不用公开私人录像。

[Godot调试工具：Remote/Local与可见形状](https://docs.godotengine.org/en/stable/tutorials/scripting/debug/overview_of_debugging_tools.html)支持面板职责；具体保存流程按当前工程和版本验证。上文是本课程操作建议，不声称已在你的电脑上测试。
