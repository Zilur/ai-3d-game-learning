# 第一次学习：先确认你和AI能做什么

这不是新的一课，也不要求额外考试。先取得一个小结果，再逐渐进入同一个「星光小庭院」。已有材料和进度直接复用，不重复配置。

## 1. 先选你现在的工作方式

|现状|可以怎样开始|不能假定什么|
|---|---|---|
|只有聊天AI|讨论概念；提供截图后分析；让AI给局部步骤或脚本，由你审阅后操作|AI能直接看见或控制Godot/Blender|
|AI能读已授权项目，但不能操作软件|让AI检查明确文件、准备局部修改；你打开软件运行|写出了代码就代表画面、手感或导出已验证|
|确有软件工具连接|先用一次只读检查确认当前对象/版本，再授权一个可撤销的小改动|一个工具连接就具备任意文件、安装、购买和执行权限|

平台生成的课堂模拟是另一种学习环境，不等于本机软件连接。无需为了第一课安装陌生插件、开远程端口或买新服务。已有连接按权限使用；没有连接照样可以用“AI给步骤、我操作”的方式学习。

## 2. 只提供最小上下文

```text
我学的课号：
当前方式：仅聊天 / 可读项目 / 已确认软件连接
已提供的软件版本与渲染器：没有或不适用就写明
现在实际有的材料：一个场景、一个对象或必要截图
上一小步的结果：
今天只想改变：
必须保持：
```

不需要密钥、账户、整台电脑目录或私人录像。错误截图保留相关对象、参数与原文，遮去不相关个人信息。AI无法访问仓库链接时只贴当前启动框和必要片段，不上传整个项目来证明自己认真。

## 3. 选一个无需完整游戏的入口

**更想从美术开始：A01。** 用你实际看到的一张图，说一条喜欢和一条不喜欢的可见特征。让AI把它转成几条候选要求，你选其中一条，形成自己的风格卡。没有图可先练语言，不能记为真实作品观察已经完成。

**更想先动手：A02。** 只需一个方块和可观察视口。先让AI给一个位置变化的小步骤，你说明预期，改完观察，再恢复。此刻不要求人物、碰撞、灯光工程或脚本基础。

下一次才进入模块与灰盒。完整参考游戏用于看目标，不是第一天需要读完和重写的作业。

## 4. 复制对话1以后怎样继续

每课的启动框现在含该课最小材料、首步、继续条件、下一步和验收证据。复制一次后可直接说“完成＋观察”或“不符＋现象”。只有AI偏离时才补发后面的修复/暂停框，别把学习变成连续填写六份提示词。

AI先示范时，看结果并作一个自己的选择；后续复测逐渐让你先提出改动和验证方案。实现依然可以委托，菜单/API依然可以查询。暂时做不到可以请求线索，不以硬撑不求助为目标。

## 5. 卡住先分类，不要一律认为自己没学会

|卡点|下一步|记录为什么|
|---|---|---|
|没有素材或起始场景|做概念模拟或列最小搭建清单；真机任务待验证|是交付/环境缺口，不等于理解失败|
|找不到对象或参数|提供当前选中对象与面板，让AI定位一个入口|菜单定位不是根因提示，允许查|
|照步骤做了但结果不同|固定条件给预期、实际与触发步骤，检验一个原因|不要连续重生成整个项目|
|讲得出却选不出参数|回到一个可重置的小对照，先预测再看结果|是具体能力的练习，不重看整套课|
|AI已经告诉了根因|当前作为有提示练习；下次换未揭示的变式|不假称本题独立诊断|

暂停前留“课号、对象/文件、实际结果、选定值、恢复方法、下一步”即可。新对话用这张卡续接，不假定AI跨会话记得你。
