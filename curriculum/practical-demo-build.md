# 实战主项目：直接搭一个“干净风格化高角度”可玩 Demo

本项目已经从“只设计课程”进入实战工程阶段。目标不是复刻某款商业游戏，而是用原创几何/合法资产实践当前参考中提炼出的视觉语言。

## 1. 最终竖切片

工作名仍为 **星光小庭院**。

第一版必须具备：

- 固定/有限的高角度镜头。
- 角色走、跑、跳。
- 一条清楚暖土主路。
- 十颗星星的收集、完成和重开。
- 一栋模块小屋。
- 2–4组树/石/花的自然簇。
- 明确留白，不把整张地面填满。
- 柔和暖主光 + 冷一点的填充关系。
- 颜色受控、偏高 Roughness、少量强调色。
- 一个可进入的视觉 A/B 实验室。
- 后续可替换为购买/二开的真实资产，而不重写玩法层。

第二阶段再加：

- 庭院 → 林路 → 观景台。
- 主环境套装的真实二开。
- 一两件 Hero 资产。
- 现成角色与基础动作融合。
- 可选训练木桩与一段攻击。

## 2. 当前工程第一版怎么搭

### 地图

```text
玩家起点
   ↓
暖土主路 ── 草地留白
   ↓
石平台 / 缓坡
   ↓
小屋支路
   ↓
远端目标
```

设计重点不是“面积大”，而是角色跑起来有空间、每个屏幕都有一个明确焦点。

### 场景元素

第一版故意只用原生几何：

- Box：地面、道路、小屋、门。
- Cylinder：树干、四边屋顶。
- Sphere：树冠、岩石、花点。
- StandardMaterial3D：受控色盘与高 Roughness。

原因：先证明**构图/密度/配色规则本身成立**，再换商店资产。否则无法判断漂亮来自我们的设计还是卖家的 Demo。

## 3. 一共七轮打磨

### Pass 1：玩法灰盒
只确认路线、净空、跳跃、星星可达。

### Pass 2：镜头
确定高角度固定/有限镜头；角色和落点必须清楚。FOV/Size只有明确收益才调整。

### Pass 3：大形与主次
放小屋、树群、石头。每屏一个主要焦点。

### Pass 4：配色
先统一大面积草/土/木/石，再给屋顶和星星少量强调色。

### Pass 5：材质
主要调 Roughness/Metallic/Emission 的层级，不先写复杂 Shader。

### Pass 6：Set Dressing
以簇为单位补花草、桶、篮子、围栏等；每加一批都做缩小图检查。

### Pass 7：灯光/VFX
最后才加 Fog、Glow、粒子、Trail、Hit Stop、Camera impulse 等；一次只解决一个问题。

## 4. 每轮的验收问题

- 第一眼看到什么？
- 主路/角色/主要目标清楚吗？
- 背景是不是抢戏？
- 这批细节删掉一半会不会更好？
- 在真实游戏距离还看得到这项修改吗？
- 旧的走跑跳/收集/重开还成立吗？
- AI有没有顺手扩大需求？
- 不喜欢时能否恢复？

## 5. 替换成购买资产时

不要整张地图一次性换完。

顺序：

1. 先选一个主环境包。
2. 只替换一棵树、一栋小屋、一块石头。
3. 固定同一镜头做 A/B。
4. 在 Blender 调比例、部件、颜色/材质。
5. 回 Godot 验收。
6. 三件都能统一后，才批量扩展。

购买策略见 [素材包采购指南](../art/asset-pack-buying-guide.md)。

## 6. “类似”到底指什么

我们学习的是：

- 高角度构图。
- 干净度与留白。
- 自然资产簇。
- 受控自然色盘。
- 柔和材质和光照。
- 模块化世界与生活感。
- 固定镜头下的视差/深度。
- 事件型打击反馈。

我们不复制：

- 商业游戏独特角色。
- 特定建筑。
- 具体关卡布局。
- 标志性道具、图案或剧情。

## 9. 当前真实状态

仓库已有基础走跑跳、十星收集、重开和概念实验。此阶段开始加入第一个原创风格化竖切片和视觉 A/B 实验室。

这不等于已经达到参考商业作品的美术品质；第一版的目的，是建立可以持续替换资产、比较效果和训练判断的真实工程骨架。
