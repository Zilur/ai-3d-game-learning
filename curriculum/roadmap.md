# 路线v4：会描述、会判断、会复用，再逐步制作

大纲经过两轮内容审核：先筛选必要知识，再检查依赖、负担与考核一致性。记录见 [两轮审核](outline-review.md)。这不是“已经完美”的承诺，后续仍需由生成课堂与真实学习证据校正。

**M=限定任务下会选择、调节、解释、验收；K=知道用途和查找方向。** 不把一个学科的全部技术细节都升级成M。每课具体停止线和题目在 [完整索引](lesson-index.md)。

## 2. 中级I01–I12：可靠的小原型

I01选择和接入现成角色 → I02动画状态与过渡 → I03资源/状态的复用范围 → I04门与平台验收 → I05模块化和简单UV → I06可进入游戏的光照方案 → I07证据驱动的优化入口。

I08导航是选修，可跳过后继续I09目标提示与交互 → I10存档/设置及恢复 → I11选定平台导出 → I12完整原型结业。机关或简单敌人按项目选一条，不同时强制。

中级仍不要求手工绑定、刷完整权重、复杂UV、Root Motion算法、数据库或全平台发布。具体M只针对验收现成资产、配置状态、恢复数据和实际交付。

## 3. 美术进阶R05–R08：长期可用的风格化资产

R05：挑合适基底，按大形→结构→细节三轮改造。
R06：统一色盘与质感，保持不同材料的差异；检查渲染和导出边界。
R07：建立小而可靠的资产套件，保留来源、许可、尺寸、原点、版本、预览和验证状态。
R08：用六件资产设计一个原创主题小场景，检验整体风格与复用。

前置是基础R01–R04以及B07–B09、I03、I05/I06。不要把美术全部推到最后，但也不要在初次建方块时学习精雕细琢。[作品入口](../art/reference-gallery.md) · [词汇](../art/visual-vocabulary.md) · [资源库流程](../art/style-and-library.md)。

## 4. 动作复用X01–X02：按需打开

I02后可选：X01筛选兼容动作、检查根位移与来源 → X02复用单次动作，调起势、接触、恢复和反馈。只做少量适配和验收，不要求原创武打、专业动捕、复杂连招。坏资产允许替换，不必无限返工。

## 5. 高级A01–A06：没有需求就不必学

A01性能证据；A02可控Shader；A03复杂旋转；A04大场景策略；A05多人认识；A06所选专项决策。A05全K、无实作要求。A06根据所选问题完成相应前置，而不是六门全通过才能做单机游戏。

## 6. 完成边界

45份独立教师输入已逐课填充；学生稿和教师反馈分离。技术C01–C32及原64项跨课题库保留，新课号题与ART词汇是细化映射，不另造技术编号。普通M一次操作/解释即可，关键M才加未知故障与迁移；K轻考，API和菜单可查。
