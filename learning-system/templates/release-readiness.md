# 小型游戏候选发布检查单

这是成人和开发者的工作单，不是儿童考试或平台认证。正式使用复制到`.learning/`或私有项目。所有初始状态为待验证，不自动导入学习成绩。与[商业成长指南](../commercial-growth.md)一起使用。

## 版本与承诺

构建标识/提交：待填写。引擎/导出模板/依赖固定版本：待填写。
目标设备/操作系统/分辨率/输入/语言：待填写。关键路线与压力情形：待填写。
承诺的内容、时长/完成方式、存档/退出恢复方式：待填写。不支持项和理由：待填写。
成人质量复核人及日期（可用本地代号）：待填写。是否选择商业发布：待决定。

## 各项单独判断，不算加权总分

每项填：待验证 / 通过 / 阻断 / 不适用（理由）。证据必须对应上面的真实构建；条件变化时重测相关项，不继承旧通过。

|维度|必要观察|状态|证据/未测边界|
|---|---|---|---|
|玩家价值与体验|未参与设计者理解目标，能够自主开始和完成；记录卡点与修改，不把亲友夸奖当市场验证|待验证|待填写|
|功能可靠性|主要路线、错误输入、重复事件、暂停/重开/退出，已知严重崩溃和无法完成问题已处理|待验证|待填写|
|数据与版本安全|需要时检查新/缺/坏/旧存档、设置持久化、升级与回退；保留原数据，明确兼容范围|待验证|待填写|
|目标设备与可用性|干净环境运行，声明设备实测；帧时间/尖峰/加载、窗口、输入、文本/静音/低运动模式按需核对|待验证|待填写|
|视觉与音频|真实玩家路线可读、风格一致、音量适当、反馈对应规则；不只看静态截图|待验证|待填写|

## 严重问题、退出条件与成年人职责

已知无法启动、主流程阻断、严重坏档、未解决高风险隐私/安全问题、无权使用内容不能由其他项抵消。轻微瑕疵可以明确接受，但必须写影响、理由与是否告知用户；“零已知阻断”不是“保证没有任何BUG”。

不需要的联网/云存档/多平台等记不适用并说明，不为完成表格给项目硬加功能。也不能对已经承诺的重要功能写不适用来逃避测试。

平台官方条款、分级/账户、版权、隐私、费用、时间、AI内容申报由成人在实际发布前再次核对。涉及合同、税务或复杂授权时按所在地寻求合适专业意见；不是让孩子背法律。平台允许发布不保证盈利。

## 三个独立决定

质量准备：待决定（附阻断/未测项）。
家庭/团队投入与是否收费：由成人另作决定，不是学习分数。
平台审核/发布时间：待实际流程确认，不由本表自动批准。

发布后第一份补丁先用副本验证升级及旧数据，记录已修复/仍未验证项；回滚程序与回滚数据分开安排。可以选择暂停、缩减或结束项目，不靠沉没成本强行发布。
