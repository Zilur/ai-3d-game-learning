# 课程设计：自学为主，伙伴陪学

持续维护的设计思想：[机制训练](modeling-thread.md) · [有依据的提问](#reasoned-questions) · [题目难度](#question-difficulty) · [沉淀与检查](#design-decisions)。这是作者说明，不是孩子要读完的新课程。

## 一条主线

做一个愿意展示的固定／有限视角3D小世界。学习者自己决定目标、解释观察并检查结果；AI帮助讲解、排错和实现。成人是安全支持和可选陪学伙伴，不是日常学习的批准者。

一次学习只推进一个有意义的小任务：**遇到问题 → 必要示范或预测 → 动手比较 → 说清发现 → 继续创作。** 不是每次强制走完一套教学仪式。OpenMAIC、原生实验、自己的项目里已经获得的等价练习不重复做三遍。

## 深度不削弱，流程减负

47课课号、前置、M/K范围、实际实验和从入门到商业作品的方向保留。M是反复会用的关键能力，K是知道用途、需要时再查；它们是课程作者的范围约束，不是孩子的评分菜单。遇到薄弱处补一个更小的例子，而不是重学整课；已经会用就减少示范。

检查关注“解释是否清楚、实际变化是否符合判断、换个条件是否还能用”。不要把三项变成每课三份作业。未测不算失败；看过解法、得到提示或软件未实际运行就如实说明。**能运行不等于理解，口头答对不等于真实软件操作。**

旧四轴与0–2格式只为保存和读取旧记录保留，不再作为家庭默认操作，不自动把它压成一个新总分；旧 `supported/independent` 字段也不再指导整个孩子或会话。帮助根据当前问题调整。

## 刻意练习系统建模，不等孩子自然顿悟

[从具体玩法到运行模型的训练线](modeling-thread.md)是作者编排图，不是新增学生必读册。A03、A05、B06积累分工、时间和状态经验；B08明确帮助提炼；B13尝试无提示迁移；C05加深数据归属；C10练不能照搬的边界；D07按自己的目标重新使用。具体任务唯一正文仍在相应教案的“这次多看一层”，由现有输入组装器直接带入OpenMAIC。

这些段落替换重复讲解或本次候选题，不叠加作业，不把共享名词复制成另一套记忆系统。重点是学习者逐渐能澄清影响规则的条件、对应真实状态、预测变化并验证；不是做一张漂亮架构图，也不是先学完整ECS。成熟实现可以借用，但不能假定AI必然正确。

入门先示范，后续比较和点明，再逐步撤掉提示。B13、D07初始学生页面只给目标和已知约束，不先泄漏字段、框图或原因；卡住时给帮助，另次换未预演条件。自动检查只验证源与组装不遗漏这条线，实际课堂是否给了判断空间、孩子是否会迁移仍要真实观察。

## 爸爸只是一位真实听众

每课在关键处或结尾择一安排一次“讲给爸爸听”，列出2–4个要点、一个演示和1–2个可共同讨论的问题。孩子用自己的话讲，双方都可以追加问题、表达不确定或一起验证。爸爸懂一些知识是优势，但不需要装成考官，也不要求装作完全不懂。

没有强制时长、评分、签字或提交记录。爸爸暂时不在就稍后分享；孩子也可先讲给同学、其他伙伴或AI练习，不把AI角色当成已经发生的亲子对话。陪伴既用于练表达，也用于交流兴趣、分享成就和增进关系。

## 学习方法是动作，不是另一门必修课

日常主要用预测后验证、自己的话解释、下次回想。专门卡在一个概念时才展开完整费曼循环；不要把每课扩为去术语、类比、反例等全部环节。跨课进深增加关系、边界或迁移距离；它与隔次回想防遗忘不是同一任务。

通用教学法优先复用OpenMAIC已核查的 `learning-to-learn`、`feynman-learning` 等Skill，不维护第二套通用教练引擎。可用能力以实际部署为准。方法组合是设计选择，不声称已经由这套课程的真人试学证明最优。

## 记录最少必要的东西

默认只留一句自己的发现、疑问或下一步；不要求录音录像、给爸爸额外工作或记录全程。OpenMAIC保存其自身运行事实，本课程本地笔记补充软件体验与未解决问题，两者尚未自动同步。

正式[记忆清单](../course/memory.md)收录需要逐渐内化的术语、判断和思维习惯，即使没有私人错题也能使用。先遮住解释回想，再举例或在软件中应用；不是逐字背诵和晨晚打卡。下次进入时最多提醒1–2个私人待回访点，可以跳过。本地工具不从一段自由文本自动评分、推断智力或生成永久弱点标签。

## 只维护四块

课程内容包、Godot／Blender实践包、一个差异Skill、可选的小型疑问记录器。详细题库、旧记录协议和自动化检查属于资料或内部工具，不要求家庭逐项执行。见[接入边界](../openmaic/README.md)。

工程内仍保留存档安全、恢复、自动测试、隐私与来源检查。这些保护不该简化。未来方向见[成长指南](../course/growth.md)；来源与研究边界集中在[来源说明](sources.md)。

## 让孩子愿意开始、能够求助，并逐渐接管判断

本轮不是给孩子诊断“学习心理”，而是改课堂可以控制的负担、选择和反馈。年龄、兴趣和经验不同；不采用固定注意力时长、左右脑、学习风格分类或保证顿悟的说法。来源与证据边界见[学习方法参考](sources.md#学习方法参考与边界)。

47份教案各有一个具体的“先从这里开始”，把当前概念连到愿意尝试的改变；带学提醒在参考区，按该课的风险提供帮助。原课号、M/K、题号、前置、恢复和素材边界保留。开场不是第二份作业，也不能替代整课能力范围；一次小成功以后仍在需要时检查未覆盖的关键关系。

**兴趣与选择。** 先看或玩一个正常的小例子，让学员选一个真正影响作品的目标。选择可以是保持原方案，不必每次二选一；暂时无想法可给可改的默认例子。美术课容纳不同偏好，机制课核对约定规则，工程课说明保护作品的价值，不把全部课程包装成猜谜或故障排查。

**有引导的探索。** 有知识可推理时先听解释，再问一项能检验它的问题，不用暗含答案的反问。缺背景就先示范；只缺入口则直接指出；卡住给具体线索，仍无进展就说明当前一小段。明确请求答案时可以解释，不先设答对门槛。支持按这次需要调整，不是按孩子永久等级调整。初始少呈现信息，不等于藏住已知规则、文件风险或禁止查看解释。

**胜任感与真实反馈。** 把难题缩到能看见变化的一小步，先正常后异常。指出实际作出的选择、证据或修正，再处理一个差异；反馈既温和又准确，不用虚假赞美或仅称赞努力代替具体帮助。AI或材料出错应由作者承认，不把失败全推给孩子。看过示范也算学习，但不冒充无提示迁移。

**表达与节奏。** 可以口述、指认、画图或演示，按任务取证，不把语言长度或菜单熟练当理解。读图和文字可结合，不给孩子贴“视觉型”等标签。专注操作时不每次打断问原因；在一个结果出来后再交流。疲倦、烦躁或想停以本人表达为准，允许暂停或缩小步骤，不从沉默、反应速度自动判断情绪。简记接续点可选，不设每日打卡债、排名或刷课奖励。

**发现与创作。** 先有具体经验，比较后适时帮助提炼，再把关系用于自己选择的一个新预测。惊奇可以来自修正预期、发现共同关系或自己预测成功，不能通过暗中改坏工程制造；没有惊奇也不是失败。阶段性综合任务先让孩子提出第一步，但不是突然撤掉全部帮助的考试。审美、试玩可靠性和自主理解分别看，不以销量或工程规模证明进阶。

**陪伴与记录。** 爸爸可以一起好奇、一起试，不代答、不审批，也不要求孩子表演讲课。记录优先借用实际可访问的会话；只保留必要的疑问、已给帮助、证据和未解点，允许本人纠正旧理解。没有历史不伪称记得，不自动建立心理画像；OpenMAIC是否跨课传递历史仍需部署验证，不由课程Skill保证。

## 本轮检查怎样落地

短卡从教案读取同一个开场，不再把分享演示直接当第一道任务；操作帮助、伙伴分享、旧问题和概念按需展开。教师反馈的公共引导约定与本课反馈一起进入生成输入，避免规范写在文件顶部却实际漏载。八个“这次多看一层”放在原参考折叠区，保留全部内容而不在初始页面抢先展开。

`tools/tests/test_learner_experience.py`检查47课开场和输入、短卡展开顺序、公共反馈依赖及原范围。已有测试继续保护素材、数据安全和题目。自动检查不是教学效果证明：真实生成课堂还需用陌生、求线索、直接求解释、已理解和想暂停等构造回应走查，再观察真实学员是否能作选择、得到帮助、解释并迁移。不要把教师走查或模拟对话伪称儿童试教。

<a id="reasoned-questions"></a>
## 有依据地提问，而不是逢事反对

提问训练服务于理解机制和自己的创作目标，不训练怀疑一切或顺从权威。逐渐形成的习惯是：先知道想弄明白什么；把已观察到的事实与自己的解释分开；问一个具体缺口；用合适的资料、比较或操作查证；根据证据接受、修正或保留不确定。有些问题是为了了解用途或表达偏好，不必都变成实验。

这是逐渐形成的思路，不是孩子每次提问必须填写的五格表。初学者问“这个词是什么意思”“我不知道从哪里看”已经合理，不能要求先带假设或证据才准求助。宽泛的“为什么”先接住，再只帮他缩小一处；无关但有兴趣的问题可自愿留下，不能羞辱为“乱问”。证据不足时允许直接说不知道。

|当前提问|怎样帮助它更有依据|停止条件|
|---|---|---|
|“AI肯定又错了吧？”|请指出与自己目标或实际观察不符的一处；没有观察先核对来源或运行|当前目标有足够证据就接受，不以反对AI为成果|
|“为什么门不开？”|先问当前距离、钥匙条件中已经知道什么，再选择能区分解释的一项操作；不是一次给全部检查表|查明当前原因并验证后继续创作，不追问所有可能原因|
|“这个词是什么意思？”|直接解释用途并给一个小例子；知识查问不要求事先证明|能联系当前任务即可，不扩成术语考试|
|“我更喜欢这个颜色，可以吗？”|先接住偏好；仅对看清路线等已选目标提出可比较问题|不同合理偏好可以并存，不追求老师同意的唯一配色|

孩子的好问题应按当前阶段判断：初期能指出不懂的具体处；中期能联系观察与目标；后期能自行选证据并说什么结果会改变判断。允许指认、画图、操作和短答，不按问题数量、反驳次数或措辞复杂度评价思维活跃。不必每课额外发问；复用原预测、诊断、迁移中的一次机会，专注创作时不强行打断。

课程中的AI错误情境是练习反例，不代表所有AI建议都错。应同时练习接受有证据的正确方案；暂时采用成熟方法、知道边界而不重证一切，也是一种有理由的决定。风险与查证成本相称：文件破坏、发布和隐私等由成人协助把关；安全可逆的颜色试验无需审查所有底层。没有新证据或条件变化时可以停止追问；存在矛盾则不为了赶进度强行宣布正确。

<a id="question-difficulty"></a>
## 题目难度：基础为主，少量可选扩展

**默认十题配比：8道基础＋2道可选扩展。** 需要平缓过渡时可用7道基础＋1道有支架的应用＋2道扩展。10题只是编排示例，不是每课配额；常态仍只选当前需要的一两道或复用一次项目证据。不能把80%基础题误当80%答对率，更不能为了维持比例故意让孩子两题做不出。

基础题并非只认词或简单的是非题：在已学范围内预测一次变化、指出一个状态归属、作一个小选择并说明依据，都可以是基础。扩展题只增加一个主要变化或少量关系的组合，不以新API、长题干、隐藏条件、谜题或跨学科知识抬难度。P预测／D诊断／T迁移／K用途是类型，不决定难度；K不因标作基础就变成背诵或实现门槛。

逐题层次在[教师反馈](../course/teacher-notes.md)中紧跟原题号标注，覆盖188道核心与76道补充题；学生正文、原题号和能力范围不增加。标注是按本课教学完成后的初始预设，不是已被真人试学证明的难度。具体学员缺前提时先示范，不把题目印了“基础”当作他应该答对的理由。拆出独立的小问后，仍按当前实际要求复核难度。

**下面只是已学B06/B07/B08/B12后可参考的十题选择，不是新的试卷或新增必做任务；实际可分次，重复证据可省。** 同一道题含多个独立判断时应拆开计数并减少其余题，不靠换一个题号掩盖额外负担。表中只点选本轮的主要判断，不把整个多问任务一次压给孩子。

<a id="design-decisions"></a>
## 设计思想如何沉淀与检查

本页保存为什么这样教及取舍；[运行模型训练线](modeling-thread.md)保存跨课出现顺序；[教案](../course/README.md)是具体任务的唯一正文；[教师反馈](../course/teacher-notes.md)保存逐题层次与答案；[记忆清单](../course/memory.md)只保存已有公共思路；差异Skill与输入组装负责把约束传到课堂。私人问题与给过的帮助属于实际会话记录，不放进公开课件。不要另建重复的教案数据库或“心理画像”。

2026-09-18本轮明确的两项补充是有依据的提问与基础／扩展配比。沿用的决定包括作品目标先行、现成场景、小示范与适时追问、具体到抽象再迁移、反馈准确但不评价人格、一次非阻塞伙伴分享、可恢复与真实证据、无自动跨课记忆承诺。研究入口仍集中在[来源与边界](sources.md#本轮学习体验修订的依据与限度)。8＋2是本项目的可调整设计选择，不宣称研究证明了普适最优比例。

维护时运行`python3 tools/check.py`，新增`tools/tests/test_question_design.py`检查逐题标注无遗漏、十题示例实际为8＋2、公共选择约定进入全部47课的两种输入、E06范围与既有能力保留。这些只证明源码和输入契约；实际课堂还要查看是否过早给答案、是否偷偷追加多问、基础是否适合当次学员。看到“基础太难／已很熟悉／提问没有帮助”时修改提示与任务，不用标签反过来要求孩子配合。
