# 课程设计：自学为主，伙伴陪学

## 一条主线

做一个愿意展示的固定／有限视角3D小世界。学习者自己决定目标、解释观察并检查结果；AI帮助讲解、排错和实现。成人是安全支持和可选陪学伙伴，不是日常学习的批准者。

一次学习只推进一个有意义的小任务：**遇到问题 → 必要示范或预测 → 动手比较 → 说清发现 → 继续创作。** 不是每次强制走完一套教学仪式。OpenMAIC、原生实验、自己的项目里已经获得的等价练习不重复做三遍。

## 深度不削弱，流程减负

47课课号、前置、M/K范围、实际实验和从入门到商业作品的方向保留。M是反复会用的关键能力，K是知道用途、需要时再查；它们是课程作者的范围约束，不是孩子的评分菜单。遇到薄弱处补一个更小的例子，而不是重学整课；已经会用就减少示范。

检查关注“解释是否清楚、实际变化是否符合判断、换个条件是否还能用”。不要把三项变成每课三份作业。未测不算失败；看过解法、得到提示或软件未实际运行就如实说明。**能运行不等于理解，口头答对不等于真实软件操作。**

旧四轴与0–2格式只为保存和读取旧记录保留，不再作为家庭默认操作，不自动把它压成一个新总分；旧 `supported/independent` 字段也不再指导整个孩子或会话。帮助根据当前问题调整。

## 爸爸只是一位真实听众

每课在关键处或结尾择一安排一次“讲给爸爸听”，列出2–4个要点、一个演示和1–2个可共同讨论的问题。孩子用自己的话讲，双方都可以追加问题、表达不确定或一起验证。爸爸懂一些知识是优势，但不需要装成考官，也不要求装作完全不懂。

没有强制时长、评分、签字或提交记录。爸爸暂时不在就稍后分享；孩子也可先讲给同学、其他伙伴或AI练习，不把AI角色当成已经发生的亲子对话。陪伴既用于练表达，也用于交流兴趣、分享成就和增进关系。

## 学习方法是动作，不是另一门必修课

日常主要用预测后验证、自己的话解释、下次回想。专门卡在一个概念时才展开完整费曼循环；不要把每课扩为去术语、类比、反例等全部环节。跨课进深增加关系、边界或迁移距离；它与隔次回想防遗忘不是同一任务。

通用教学法优先复用OpenMAIC已核查的 `learning-to-learn`、`feynman-learning` 等Skill，不维护第二套通用教练引擎。可用能力以实际部署为准。方法组合是设计选择，不声称已经由这套课程的真人试学证明最优。

## 记录最少必要的东西

默认只留一句自己的发现、疑问或下一步；不要求录音录像、给爸爸额外工作或记录全程。OpenMAIC保存其自身运行事实，本课程本地笔记补充软件体验与未解决问题，两者尚未自动同步。

正式[记忆清单](../course/memory.md)收录需要逐渐内化的术语、判断和思维习惯，即使没有私人错题也能使用。先遮住解释回想，再举例或在软件中应用；不是逐字背诵和晨晚打卡。下次进入时最多提醒1–2个私人待回访点，可以跳过。本地工具不从一段自由文本自动评分、推断智力或生成永久弱点标签。

## 只维护四块

课程内容包、Godot／Blender实践包、一个差异Skill、可选的小型疑问记录器。详细题库、旧记录协议和自动化检查属于资料或内部工具，不要求家庭逐项执行。见[接入边界](../openmaic/README.md)。

工程内仍保留存档安全、恢复、自动测试、隐私与来源检查。这些保护不该简化。未来方向见[成长指南](../course/growth.md)；来源与研究边界集中在[来源说明](sources.md)。
