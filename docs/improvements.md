# 下一阶段的完善顺序

当前先把课件和逐步对话做好，已有运行示例不扩写。v6新增地图、美化和轻战斗仍是详细教学规格，不是成品。

## 先验证不同教学形式

空间参数、碰撞因果、材质对照、事件状态各选一课生成；再验证I13布局和X02时间窗口。每课检查复制对话、暂停/恢复、错误分支和M/K边界。不是只看PPT美观。

## 再制作课件对应的最小配套

先把已有基础场景按课切成起始/完成/可恢复故障。然后接三段灰盒、一个转角美化样板、最后单独训练角。每次人工检查再并回主项目，不另造第二套完整游戏。

## 参考和视觉材料

按课程要求补真实软件截图、同机位前后对照、许可明确的动作/模型。三处游戏机位及训练角时间线优先。概念结构图已有，真实成品图仍须实际制作，不能伪造为已运行截图。

## 学习与发布验收

让学员仅靠本课启动框与必要材料完成一次任务，记录在哪一步困住。换一个新情境检查关键能力，普通理解项不加作业。最后在选定目标设备做首次启动、完整十星路线和重开；增强版再验命中和恢复。
