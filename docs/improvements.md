# 课件v4之后：按证据推进，不再反复扩张大纲

本轮已完成两轮大纲审核、45份逐课课件/学生稿、艺术观看入口、界面深度与上游Skill参考。还不能称45堂课堂全部可用，更不能称45个真实软件实验齐全。

## 第一优先：实际生成与交互验收

选择B01A、B04、B08、B10、R01、R04六种代表形式。逐一检查初始状态、操作范围、反馈、故障、复位、答案时机与可读性。记录生成配置和失败点，修模板后再扩大。不要一次生成全部后发现同一个模板错误重复45次。

## 第二优先：完整图片与素材计划

按课号列真实需要的图，不为装饰堆图。艺术大师作品默认保留原站观看；公开课程的示例优先原创或许可明确的图。每图记录来源、用途、署名与权限。逐课替换当前明确标示的形状/状态卡等替代方案，不能把占位示意叫完成素材。

## 第三优先：真实软件小实验与参考

由已经稳定的课件决定起始场景、完成参考、一个可恢复故障和最小验收。优先B04碰撞、B03移动、B08共享材质，再补静态资产往返和美术小套件。现有工程先保留，不边写课件边另造复杂游戏。

## 第四优先：试学和长期资产库

用最小记录验证关键M是否能在新情境独立完成；初次兴趣与隔次掌握分别记录。资源库先六件同风格资产，再按真实用途增加；不要囤积海量无统一规格素材。
