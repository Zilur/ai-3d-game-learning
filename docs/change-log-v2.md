# 从Foundation v1到Interactive Mastery v2

原课程保留在course/foundation-v1及PR#1历史。本版放在独立分支，不自动合并。

## 主要变化

把“必须掌握/必须认识/用到再学/暂时忽略”改成统一M/K。把自我勾选升级为预测、实操排错、迁移三类证据；答案与练习分离，补延迟复测和提示记录。

B01拆成三个微单元，修正父空间与物体自身方向的混淆，区分Origin与操作Pivot。补B04碰撞、B08材质、B10事件三个不同类型的OpenMAIC样板输入。

初级16课、中级12课均有产物、概念、实验和验收路径。26个核心概念簇各配P/R/T，加12个K用途题，共90项训练。打印要点与闭卷回忆单独立维护。

新增Godot工程、空间/门轴/材质实验、星星收集参考实现、原创星星OBJ、Blender生成脚本、UV诊断Shader。音效和粒子仍是B11实践扩展，不宣称已经制作完整美术包。

新增离线内容验证与固定引擎headless行为测试、CI与人工验收记录。测试脚本、实际运行结果、视觉质量、学习效果分别标明，不能相互替代。
