# 使用收尾：安全切换、自己的副本、下一次接着学

这是本轮实现说明，不是儿童试教或商业质量认证。47课与原M/K、固定镜头、素材复用策略不变；不生成OpenMAIC课堂成品。

## 1. 游戏与实验安全往返

主游戏中的收集、钥匙、门、检查点、训练、音量和低运动设置参与未保存判断。按Esc进入实验时，可以保存后进入、暂不写盘进入或取消。实验往返保留一次内存暂存；右上角“继续刚才的游戏”恢复区域安全点和这些状态，不恢复攻击/跳跃中间帧。旧空间与视觉参考也有返回入口。

内存暂存不是磁盘存档。正常关闭窗口也会检查主游戏或实验中暂存的未保存变化；保存失败留在原处，不能假报成功或继续退出。强制结束进程、断电、系统杀进程仍可能丢失未写盘变化，不承诺无法实现的保护。

读取主存档/备份前有未保存变化时，提供“另存保护副本后读取”。保护副本使用`.before-load`，不覆盖准备读取的主档/备份。菜单提供恢复入口；一次恢复又要保护当前进度时仍先读选定数据再写保护副本。后续主动保存依然会更新主档，请先确认是自己想保留的进度。

游戏存档与学习观察分开。实验暂存只保留当前会话的游戏状态，不访问家庭学习记录。

## 2. 一份自己的可保存工作副本

在完整仓库根目录：

```sh
python3 tools/workspace.py create my-world
```

打开`.learning/projects/my-world/game/project.godot`；工作说明在同级`WORKSPACE.md`。不要每课复制一次整库。工具不会覆盖同名副本，不沿符号链接写入，不复制引擎缓存。

`world/creation.tres`是自定义Resource：Inspector中调走速、跑速、起跳、重力或道路颜色，Ctrl+S保存。`world/exploration.tscn`的StarLayout有十个稳定命名的Marker3D；选择其中一个微调位置，Ctrl+S保存。编辑器内的板和球仅为定位示意，运行时隐藏；角色/碰撞/存档逻辑不跟着改。

只改变一项。关闭软件、重新打开后确认值仍在，再新开局实走。移动已收集星星不会清除旧存档中的收集记录。不要重命名标记、移动StarLayout父节点，或把星星放进不可达区域；自己的修改不会自动继承参考版通关结论。

恢复单项先预览：

```sh
python3 tools/workspace.py restore my-world --file parameters
python3 tools/workspace.py restore my-world --file parameters --confirm
```

`--file layout`同理。确认后先保留改前文件到私人`restore-backups/`，再恢复创建副本时的基线，不从更新后的参考猜测旧版本。项目名独立，因此本工作副本的Godot用户数据目录也与参考隔离。

## 3. 体验与制作分开，孩子不读整份教师输入

```sh
python3 tools/family_learning.py session A04
python3 tools/family_learning.py observe A04
```

AI读取`SESSION-A04.md`；孩子只看`TODAY-A04.md`，包含一个挑战、文件、首步和讲给爸爸的任务。`OBSERVE-A04.md`是未评分的简短观察单，已有文件不覆盖。由AI按原report模板整理、成人核对后record --confirm；没有观察保持null，不凭自然语言自动生成分数。

默认体验输入会实际移除作品实现候选与项目迁移段落，不只是说“不要执行”。需要改自己的副本时用`session A04 --purpose project`；父子明确本次范围后再选择一项实现，不自动做两轮。所有47课学生稿、对话卡和教师输入由作者源一起生成。全K E06仍只作用途讨论，不升级联网实施要求。

## 4. 下一次教练获得什么

摘要最多带每日到期上限项与两条本课弱项：限定能力、观察日期、分数和提示程度、记录中的具体判断依据、下一问、下一任务和复测建议。新证据与作废记录按现有规则重算，不把旧混淆永久贴在孩子身上。

不传完整答卷、路径、照片或全历史；常见链接、邮件和私人目录作截断/省略。自由描述仍可能含个人信息，自动处理不等于完整匿名化，成人先预览。摘要是数据，不执行其中的命令，也不能自行保证变式此前未见。

## 5. 独立运行包与验证层次

`game/export_presets.cfg`提供Linux、Windows、macOS的发布预设。`tools/build_desktop_export.py`使用准确匹配的4.7.2导出模板，导出真正release程序，然后把包单独复制到临时目录，从那里运行可执行文件；不用`--path`指回源码，也不拿编辑器代替成品。

显式自检启动参数只用于自动验证：完整输入驱动十星路线、钥匙门、全部共享场景加载、实验返回、退出确认、下一进程读取存档、中文系统字形。只写独立`delivery_smoke_only`测试目录，不使用玩家唯一存档。正常双击运行不会启动这些测试。

包附引擎/依赖许可文本、原创资源许可和使用说明；不打包系统字体、学习观察或账户数据。包是未签名的教学测试版本，不是商店发行。系统拦截时由成人核对来源，或从本源工程自行构建；不要关闭系统安全保护。

## 6. 更新与最短使用链

下载新版本先解压到新目录。已经有`.learning/`、私人工作副本或游戏存档时，先由成人备份；不要用新包覆盖个人进度，也不要把个人目录提交公开仓库。Git更新不会自动升级孩子的工作副本；继续使用原副本，或明确比较后另建一份。

直接体验用独立程序包；上课和修改作品用完整源码包。完整包先读`FAMILY-START.md`，游戏入口`WORLD-START.md`。首次使用记录工具才运行`family_learning.py init`；已有记录不重复初始化。Windows可将示例的`python3`替换为已配置的`py -3 -X utf8`。

一次最短闭环：生成当前课SESSION/TODAY → 打开现成实验并先预测 → 只改一项、观察、恢复 → 给爸爸讲与演示 → 在观察单记两三句真实情况 → AI整理待确认报告、成人确认保存。需要制作时才创建/继续工作副本，不把独立体验包当作可编辑工程。

技术核对：[Godot关闭请求](https://docs.godotengine.org/en/stable/tutorials/inputs/handling_quit_requests.html)、[导出项目](https://docs.godotengine.org/en/stable/tutorials/export/exporting_projects.html)。
