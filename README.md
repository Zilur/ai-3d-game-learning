# AI时代：做一个精致的小型3D游戏

**学一点概念 → 跟AI做一小步 → 亲自调和观察 → 放回同一项目 → 检查没改坏。**

## 从哪里开始

[开始学习](START-HERE.md) · [全部课件与逐步AI对话](curriculum/lesson-index.md) · [精致Demo的具体标准](curriculum/demo-quality.md)

每课有三份用途明确的内容：学生稿、可整份给OpenMAIC的教师输入、可逐框发送给AI的对话卡。47个单元不是141堂课；不要求所有人学完选修。

主项目「星光小庭院」先做十星收集小循环，再扩成庭院—林间路—观景台的可探索回路。基础版做到可玩、可辨路、风格统一、可恢复和可交付。增强版在旁路增加复用动作的训练木桩，不做复杂ACT，也不影响主线完成。

## 只把精力用在重点

**M必须掌握**：会选择、亲调、判断结果与验收；不要求闭卷手写全部代码。
**K理解即可**：知道用途、何时查询；不要求实现和详细排错。

每课已给第一小步、继续条件、失败分支与进度卡。普通M用一次有效操作和解释留证；关键薄弱能力再做变式。查菜单/API和使用AI初稿不算没有掌握。
