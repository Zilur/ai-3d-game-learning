# 星光小庭院：可复用原创资产套件 v1

12个已经导出的GLB：小屋、阔叶树、松树、石簇、花簇、桥、围栏、灯、路牌、木桩、观景平台、信标。
本轮选择的是原创生产参考套件，不是虚构已购买了某个商用包。全部用于三段地图；角色沿用已有原创骨架样本。

单位米，+Y朝上，静态物体原点在底面；色盘和低反光材质统一。GLB可以直接导入Godot或Blender二开，不依赖外部贴图。
几何和材质与碰撞/游戏状态分离。替换外观不应替换物品ID、检测规则、存档字段或主角控制器。

`manifest.json`记录各文件的SHA-256和三角形数；`tools/build_world_assets.py`是作者复建工具，学员不必执行。
这些模型已经实际接入参考关卡，但“最终美术满意”“商业品质”仍需要用户和玩家验收，不以文件存在宣布通过。
