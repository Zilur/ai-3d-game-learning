# 素材与使用边界

| 素材 | 来源 | 用途 | 限制 |
|---|---|---|---|
| star.obj | 本项目原创程序生成 | 无外部依赖的星星网格 | 22顶点、40三角形；没有UV/动画/贴图，不用来做UV练习 |
| 场景中的方块、胶囊、球、门板 | Godot内置基础几何 | 尺度、碰撞、材质实验 | 不是美术成品包 |
| uv_checker.gdshader | 本项目原创诊断Shader | 在自带UV的BoxMesh/SphereMesh上观察UV格子 | unshaded，不用于比较PBR灯光 |
| Blender星星 | blender/create_star.py生成 | 练习源资产、原点、GLB往返 | 用户自行保存.blend和导出GLB，脚本不覆盖已有文件 |

OBJ的+Y向上，外半径0.5，厚度0.16；边界宽约0.951，高约0.905，**不是宽高都一米**。Blender脚本将坐标转成+Z向上，导出glTF时再核对朝向和尺寸。

没有加入第三方音效、模型、图片或字体。公开分享不自动等于已授予许可证；维护者在对外发行前决定本项目许可，第三方资产另行登记。不要把未来用户提供的版权素材默认为可再分发。

星星OBJ用于网格导入。正式Blender→Godot往返练习使用GLB，不据此声称OBJ支持完整材质/骨骼工作流。
