# 星光小庭院：主游戏与原生实验

使用Godot 4.7.2导入`project.godot`，F5运行`world/exploration.tscn`。
默认主游戏已连接庭院、林路、观景台，包含十星收集、钥匙门、可选木桩训练、暂停、静音/低运动与主动保存继续。

按Esc进入菜单或实验目录；也可打开`labs/lab_hub.tscn`按F6。
旧`scenes/main.tscn`和A03起点保持，供原课程与回归使用，不和新主游戏混称。
