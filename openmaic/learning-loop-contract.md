# 交互课堂与软件实操的共同教学约定

这是作者/生成器使用规范，不要求新手背下来。47课保持同一课号和M/K。单课全文必须自足，不能只让学生去找另一份模板。

## 一个循环只有一个主要问题

结果/差异可见 → 短示范（需要时） → 一个预测 → 一个控件操作 → 一句原因解释 → 对应软件Lab → 本课记忆规则 → 已到相应生产阶段才迁移。

不用固定幻灯片页数。新词随现象给中文解释，首个操作前不集中堆软件百科；一次小步通常只引入一至三个新词，这是可调整编排建议，不是认知容量定律。朗读提示词和权限清单不算教学。

## 渐撤帮助

初次由AI示范一个可逆小操作；学员换一个值。再次只给要观察的现象；学员选参数。检查时换未揭示的对象/约束；学员先判断，AI可执行。即便实现由AI完成，也能评价选择、解释、范围与验收。

连续两个有区分力的问题仍不能说明，就降低到一个变量的对照，给反馈后补练；不无限追问、不盲加题量。延迟再测只针对关键M。K只做用途认识，不复制M整套考核。

## 软件衔接必须准确

显示文件路径、打开方法、唯一首步、固定不变项、观察、恢复和局限。Godot先导入game/project.godot，再打开指定.tscn运行当前场景；Blender打开指定.blend，先另存学习副本。快捷键可查，不考试。

有文件不等于该课所有M都已配套。实验可能只覆盖部分能力：例如碰撞开关Lab没有完整Layer/Mask筛选练习时，应转Inspector并加入已说明的对照对象，或把M2留待验证；不能用M1通过补M2。

运行时滑块、脚本自定义参数、软件内置属性要分清。保存为最终值须写回正确场景/资源并重开复测。截图不冒充滑杆，课堂模拟不冒充Godot渲染。

## 复位与可访问性

复位须同步真实状态、控件和读数；另提供“重播动作”和“恢复默认值”的区别。可键盘操作，颜色与声音之外也有文字/形状反馈。低运动模式仍能完成题目，不因关闭震屏而扣分。

## 生成后怎样验证

对每课检查：预测前答案未泄露；控件的改变与因果一致；范围与默认值正确；复位无残留；跟AI的第一框含Lab路径、下一步与停止点；缺素材分支诚实；关键题不靠“都可以/不一定”猜中；评分对应M/K。

代表课至少覆盖A04职责、A06参数、B04视觉与共享、B06时序、D01二开。先检查生成课堂和真实软件各自正确，再安排实际新手试走；不能以作者成功执行替代学习验证。
