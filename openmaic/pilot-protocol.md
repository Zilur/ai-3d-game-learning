# 代表课堂试教：先证明能学，再复制制作

状态：待执行协议。本文件没有生成课堂、运行浏览器控件或收集真人数据；记录表不得预填“通过”。不需要先部署平台或启用收费服务，使用你已选定且已授权的环境。

## 1. 先选不同类型，不平均铺开47堂

|样本|想验证的风险|最低观察|
|---|---|---|
|A01风格对话|没有图也假装观察；把教师偏好当标准|参考确实可见，学员能选一项借鉴与排除；无图明确降为语言练习|
|A03节点与实例|能背定义但选错修改对象|选择与画面同步；整体和外观分别改；可恢复|
|B04材质|预览条件混乱，共享与固定基线冲突|独立A/B先成立；共享时两球才一起变；复位关系正确|
|B06拾取|效果消失掩盖重复或无效事件|日志与状态一致；错误对象、重复请求和复位可区分|
|C02世界美化|只看好看静图，落点/路线却不可用|同机位比较与示意路径检查分开；真机实走仍待对应工程|
|D06训练角（选增强版才测）|动作播放当命中，或第二轮状态没恢复|窗口/范围/次数与反馈一致；第二次攻击与中断可检查|

先做一个样本，修模板后再测另一类；不是用户必须一次上六节课。

## 2. 生成前的输入检查

从课程索引拿单课OpenMAIC全文，保留教师区供生成反馈使用，不提前展示给学员。确认平台实际支持的互动类型。老师指令中的“实测控件”是验收要求，不是模型声称自己完成就算实测。

课中不要朗读六大段提示词和全部安全说明；呈现目标、一幅概念图、一次因果对照和可复制的AI工作入口。余下说明按需展开。没有3D能力可用能保留同一关系的2D/状态模拟，但必须标示，不可用点击后只换标签的假控件代替实验。

## 3. 两条独立的试走

**课堂路线：** 进场能找到第一步 → 作预测 → 真的改变一个条件 → 观察反馈 → 恢复 → 做一个必要判断。若控件不工作，这是课件问题，不先判学员不理解。

**新AI对话路线：** 只复制对话1，不附其他课件 → AI能说清起点和第一步 → 学员给观察后只推进下一步 → 结果不符时局部验证 → 暂停后产出进度卡。没有软件工具连接时，AI须给操作单而非宣称已改项目。

这两条都好用以后，再测真机配套与未提示迁移；一次“喜欢课堂”的反馈不能替代它们。

## 4. 用最少记录改课

```text
课号/课件提交版本/平台与模型配置（不含密钥）：
实际尝试了什么：
第一处卡点：找不到步骤 / 不懂概念 / 控件无反应 / 环境缺失 / AI越界 / 其他
作答前是否见到答案：
一项参数变化与结果是否一致、能否复位：
对话1能否独立续接：未试 / 可用 / 不可用
真机应用与迁移：未试 / 有提示 / 独立取证（附足够的事实）
下一轮只改：
```

不强制采集学员面孔、姓名、账号或完整录屏。自学者可保存在本地；公开反馈只保留必要、去个人化的现象。

## 5. 停止复制的条件

有答案提前泄露、无响应控件、复位不完整、提示词缺上下文、模拟冒充真机、K变成深考，先修样本。不要因结构检查全绿就批量生成剩余课堂。样本通过也仅说明该版本与条件下通过，后续换模型或平台再抽查。
