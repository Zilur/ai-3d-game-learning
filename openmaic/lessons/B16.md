# B-10｜初级结业：把星星换成另一种可用物品

> 兼容课号：B16。ABCDE是主题入口，不是必须按字母顺序完成；文件链接与题号保留稳定。

版本：Guided Demo v6｜2026-09-15
状态：课件正文与互动规格已编写；尚未逐课生成OpenMAIC课堂或试教。

## 1. 本课任务卡

**产出：** 用已学知识完成一种新拾取物，并证明关键条件没有被破坏。
**前置：** B15；**对应概念：** C05/C06/C07/C12/C16/C18/C20。
**预计课堂：** 20–30分钟，可在实验前后暂停；不含后续真实软件制作时间。
**M 必须掌握：**
- 迁移外观、检测、一次性状态和反馈。
- 对AI修改做功能回归并解释结果。
**K 理解即可：**
- 只抽本阶段已经介绍的用途词，不增加新术语。
**停止线：** 不突然加入敌人、背包、绑定、多人；不要求做完整跨阶段题库。

## 2. 必要讲解：先看现象，再给术语

迁移不是逐步抄原星星：新道具可能更小、颜色更接近背景，检测与反馈要随用途核对。实现可以由AI完成，选择、预测和验收由学员承担。

提交最少证据：需求一句、改动范围、一次正常测试、一次关键异常、一个次日变式。不会某项就补对应实验，不重看全部课程。

## 2A. 场景、概念图与逐步AI对话

**实际位置：** P05｜把星星经验迁移成一颗能量果。

|能照着做星星，但换外观和奖励就不知道改哪里。|同庭院出现一种新拾取物，原星星循环保持，修改职责清楚。|

### 复制第1框开始；以后每次只发当前一步

**学员用法：** 无需一次读完所有提示。将当前框发给你使用的AI；做完后回“完成＋观察”，结果不符回“不符＋现象”，报错回“报错＋原文”，需要停下回“暂停”。自然语言也可以。不要一口气把六步当成自动执行授权。

### 对话1｜建立本课上下文

```text
请做我这节课的协作教练：B-10（兼容课号B16）《初级结业：把星星换成另一种可用物品》。
我们逐步制作同一个「星光小庭院」，当前只解决：能照着做星星，但换外观和奖励就不知道改哪里。
目标：同庭院出现一种新拾取物，原星星循环保持，修改职责清楚。
必须掌握：迁移外观、检测、一次性状态和反馈。；对AI修改做功能回归并解释结果。。理解即可：只抽本阶段已经介绍的用途词，不增加新术语。
停止线：不突然加入敌人、背包、绑定、多人；不要求做完整跨阶段题库。
必须保持：原星星计数、完成条件、重开、移动和镜头保持。
先读取我已提供的进度和材料，只问真正缺失的一项。需要软件操作时核对实际版本、当前截图或场景树、可访问的工具；不要求我发密钥或整个电脑。
先给一个预测问题并等我回答，再给一个最小步骤。不跳课、不自动做整款游戏。能执行才说已执行，否则给明确操作单或脚本，并标未执行。
后续每轮用四项回应：现在是哪一步；只改什么/怎样恢复；我应观察什么；目前还缺什么证据。没有证据不要替我勾通过。
```

**AI此时应做：** 确认当前场景与学习范围，不直接输出几十个文件。已经提供过的版本、素材和约束应复用，不重复问。

### 对话2｜先理解一个因果关系

```text
先问我：只换颜色就一定成为合格新拾取物吗？
等我写预测和理由后，再指出一个证据缺口，只给一个提示，不先公布完整答案。用词不专业时先确认意思，再补术语。
```

**转入下一步：** 有自己的预测即可；预测错可以用实验纠正，不要求先背定义。

### 对话3｜AI只完成第一小步

```text
沿用已确认的版本、材料和修改边界。现在只做：先让我自己提出一种新计数拾取物，说明哪些职责复用；只检查范围，不给完整解。
先列影响对象和原值，再提供一个可撤销初稿。没有实际软件连接时给我可执行的局部操作单/脚本，不说已经修改。做完先停下。
```

**预计看到／拿到：** 我能将外观、检测和计数职责说清，并选出最小修改。
**不是自动保证：** 这是验收目标，取决于实际模型、工具和输入；结果不同就走下方“不符”分支。

### 对话4｜人观察与亲调，再继续第二小步

```text
这是我刚才的实际结果：我会附一张当前图、短演示或必要日志，并用一句话描述差异。
先检查是否满足：我能将外观、检测和计数职责说清，并选出最小修改。
若满足，指导我先亲调下面表格的一项；我回报观察后才继续：按我的选择协助实现一个版本，换一种情境复测关键理解。
一次只动一项可见参数。方向接近就手调；结构有误才给局部修复，不能不断重生成整个场景。
```

|选中哪里与参数性质|这次亲自试什么|观察与停手依据|
|---|---|---|
|新物品视觉材质与尺寸（内置）|固定机位调整可辨性|与星星是否分得清，实际尺寸是否合理|
|检测形状与奖励值（内置/自定义）|分别调范围和奖励，不同时改|一次触发范围及能量变化是否符合目标|

**保存与恢复：** 先记录原值和实际对象。优先在安全副本试；运行中Remote Inspector的变化不要当成已保存的设计值，确认后将选定值写回本地场景/资源或配置并重新运行。菜单路径随版本核对，自定义变量不冒充内置属性。
**采用哪种沟通：** 大方向偏了，用参考图圈出要借鉴的轮廓/色彩/光感，并指出不要照搬什么；单个视觉值接近了，先拖或输入数值；原因不明，固定条件做一次对照。参考图不是可自动反推所有参数的答案。

### 对话5｜成功验收，或失败时只修一处

**达到目标时发送：**
```text
请只根据我提供的证据检查：
- 能独立决定外观、检测、状态和反馈各改哪层。
- 能提供新物品一次性行为与旧星星循环回归的证据。
旧功能回归：收齐原星星并重开；重复碰新物品不重复奖励。
缺少过程证据就标待验证；不得用一张截图证明走跳或一次性事件。不要新增需求或把所有候选题变成作业。
```

**结果不符或报错时发送：**
```text
不符/报错：我会提供触发步骤、预期、实际现象和必要原始日志。
保留：原星星计数、完成条件、重开、移动和镜头保持。
本课优先风险：检查AI是否直接替换全部星星需求，或用两个显示计数掩盖状态耦合。
先提出一个可推翻的假设和一个最小验证；不要同时改多个系统。若两次验证仍无进展，回到基线并列出缺失证据，不反复抽卡。不要删除测试、关闭需求或扩大权限来假装修好。
```

**AI评分边界：** 代码和初稿可以由AI提供；判断、亲调与证据解释由学员完成。得到根因提示记为有提示，不因此重复考试所有概念。

## 4. 互动实验规格

**初始状态：** 可选果实/能量球两张需求卡，已存在检测和计数流程；不预先给目标参数。
**可操作项：** 选择外观尺寸、材质、检测范围和反馈；测试正确/错误对象、重复/重开。
**实验步骤：**
1. 先写新物品与星星有哪些相同、不同时。
2. 限定AI只改必要对象，学员自己选参数并测试。
3. 抽一个未见故障，然后换另一种大小或颜色复测。
**预期反馈：** 按功能证据判定，不按美术复杂度或代码数量。缺证据时标待验证。
**故障或反例：** 随机一个故障：Mask、共享材质或未重置；不得同时塞三个让学员猜。
**复位：** 恢复原星星版本，保留新方案为独立练习副本。
**无图/无3D替代：** 用原创简单形状、状态卡或给定时间序列表达同一因果关系；标明“示意”，不得把预设结果说成Godot/Blender实测。不能以假按钮或不响应的截图代替交互。
**完成判据：** 对本课两项M提供操作或判断及解释；一个实验可覆盖多项。只有关键M或发现薄弱处才追加故障/变式，不为每个术语加作业。
