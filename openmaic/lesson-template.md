# 单课统一规格v6

实际可复制输入见[课程索引](../curriculum/lesson-index.md)，本页供作者维护，不要单独用它生成空课。

一课最多两三项必须掌握能力，必要理解项按需出现。按同一顺序填：具体问题与结果 → M/K/停止线 → 必要概念 → 职责/因果图 → 连续AI对话 → 单变量实验 → 候选训练与教师反馈 → 项目应用与恢复 → 下一步。

连续AI对话必须有：独立启动框、第一小步、实际继续条件、第二小步、人工微调入口、成功与失败分支、暂停摘要。不能只有一句“请AI帮我做”；也不能默认AI已连接编辑器或看过材料。

每个手调项说明对象、入口性质、如何比较、原值保存与恢复。没有通用最佳数值，不强制记菜单。运行预览值与持久保存值分开。K认识课只做用途决定，不套六次软件实操。

所有生成稿由同一作者源构建，学生稿不含教师答案，教师稿可整份输入OpenMAIC，对话卡可单独发给协作AI。用户无需拼文件。功能、美术、课堂与学习效果的完成状态分别记录。
