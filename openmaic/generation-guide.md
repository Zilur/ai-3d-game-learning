# 一课一输入，概念学习后直接进入AI协作

## 最简单的用法

在[课程索引](../curriculum/lesson-index.md)选择一课，打开「OpenMAIC全文」，复制全文作为需求。不要一次喂整套47课，不必再手工拼模板。软件版本和个人进度由实际学习时补充，不把API密钥放入课件。

每份输入都有：任务卡、必要讲解、概念关系图、分步AI对话、参数实验、失败分支、M/K候选训练、教师反馈、主项目验收。教师答案用于反馈，不应出现在首次题干或幻灯片上。

## 对生成器的明确要求

先按本课目标组织少量页面：任务/观察 → 一个因果互动 → 参数或情境对照 → 与AI继续的卡片 → 一次应用验收。不要把每段提示词全念成讲稿。重点是用户能动手或做选择，不是幻灯片数量。

第2A节的对话卡应可复制，按步骤逐张展开；复制按钮必须实际可用。点击「已完成」不是自动评分证据，不能伪称已经连接学员本地软件。没有剪贴板能力就显示可选中的完整文字，不制作假按钮。

概念图按职责/因果重绘。Mermaid不支持时画等价方框图，不直接把代码贴在屏幕上。静态参考和简化模拟要标明，不能冒充真实Godot/Blender截图。图与控件缺失时，说明缺口再采用诚实可用的替代。

AI作为课堂教练应一次给一步。学员回报后才给下一步；「不符」走局部诊断，「暂停」给进度摘要。未选的导航、战斗或高级内容不能变成毕业门槛。

## 生成后验收

检查本课M/K没有扩张；控件真改变结果且可恢复；答案延后；AI对话能复制；K课不强制操作；无材料时明确待验证。再在真实软件按本课证据验收，不以课堂看着流畅就宣称掌握。

当前文本更新没有调用生成服务。官方部署与API流程见[固定上游Skill](upstream-reference.md)。其操作规程与课程内容不是一回事；使用时检查实际服务能力，不承诺某网站版本已有本仓库所有自定义界面。

## 学习方法与个体记录的分工


普通概念课选少量learning-to-learn动作；专门补弱项再用feynman-learning；系列进深参考spiral-curriculum。它们是实际版本工作台中的可选技能，不是所有页面默认运行的功能。保留本课程固定课号/MK和亲子任务，不因加载技能而给孩子增加多套作业。

`family_learning.py session A04 --openmaic`输出教师输入，默认不含私人历史。需要个体摘要时先用`python3 tools/openmaic_handoff.py A04`预览，成人确认后加`--confirm`生成独立私人附件；不放进公开课程或共享课堂。没有自动学情回传和自动打分。详情与源码证据见[能力核查](capability-audit.md)。
