# 作品观看与艺术家参考：看完要能说出一条规则

核对日期：2026-09-15。下面优先链接原作者或机构页面。**本轮交付的是观看入口、选择方法和练习，不打包第三方原图。** 网页可看、图片可下载、可临摹、可公开展示、可商用、可再分发是不同问题；本课程不作一概许可判断。

## 从五个方向看，不必追排行榜

|观看入口|建议先观察什么|只做一个小练习|先不模仿什么|
|---|---|---|---|
|[Mary Blair / Walt Disney Family Museum](https://www.waltdisney.org/mary-blair)|色块、形状与童趣表达；该页为展览资料，不代表展览仍在举办|选一张作品，记五个大色块与第一焦点，再换成自己的小屋主题|具体角色和整幅画面的逐像素复制|
|[Eyvind Earle 官方](https://eyvindearle.com/)|树木节奏、远近层次与装饰性大形|只归纳远中近三层的明暗或形状节奏，用原创块面换题材|直接转载其图片；官网对网络使用有明确限制|
|[Roman Klčo / Polygon Runway](https://polygonrunway.com/)|风格化3D小场景的比例、构图和光照|选一个小场景，只分析轮廓和三类材质，再设计不同道具|把所有课程完整刷完；部分课程收费，不是本课必买项|
|[Grant Abbitt / Gabbitt Media](https://www.gabbitt.co.uk/)|简单形体如何逐步组织为可读模型|选择相关主题的公开示范，自己先预测下一步，再做一处变式|初学就完整手工角色绑定、雕刻和全部拓扑流程|
|[Daniel Merriam 官方画廊](https://www.danielmerriam.com/)|梦幻建筑的轮廓、尺度夸张与想象性组合|只提取一个屋顶/塔楼比例规则，换成自己的邮局|复杂纹样总量；细节密度不作为小游戏质量门槛|

## 补充浏览网站

[ArtStation](https://www.artstation.com/)用于找作品与作者过程说明。建议搜索`stylized environment breakdown`、`hand painted props`、`storybook 3d`、`diorama blender`；优先有过程图、作者和用途说明的项目，不只按热度。看到摄影级作品不需要跟着转向写实训练。

[Sketchfab](https://sketchfab.com/)作为3D作品浏览入口；可访问和查看方式随地区、账号与具体页面变化。旋转查看能帮助观察背面与轮廓，但是否可下载和如何许可要看每件作品；无法访问就用作者的多角度图，不让平台成为学习前提。

[Kenney资产](https://kenney.nl/assets)与[许可说明](https://kenney.nl/support)、[Quaternius](https://quaternius.com/)更适合找基础模型与套件。Kenney说明其资产页采用CC0，仍保存下载包附带说明；Quaternius按具体包核对版本、免费/付费层与许可，不把整个网站一概当无条件素材池。

[Adobe Mixamo FAQ](https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html)用于动作复用前的适用性核对：官方列有账号/地区限制，自动绑定面向双足类人角色，夸张比例等可能不适用。它是候选来源，不是课程唯一依赖；原文件再分发需另核对具体条款。

## 你的偏好怎样转成检索语言

“唯美、卡通、漫画”先拆成候选，而不是硬定一种技术：

- 童趣绘本：`storybook / painterly / whimsical`；观察温柔大色块、形体节奏和环境叙事。
- 软质玩具：`stylized / soft shapes / toy-like / diorama`；观察圆润比例与受控反射，不等于所有材质都塑料。
- 漫画分块：`toon / cel shaded / graphic shapes`；观察明暗边界和轮廓，具体Shader属于按需专题。
- 微缩景：`stylized diorama / low poly environment`；观察少量模型如何构成完整画面，不等于越少面越好。

这些是查图方向，不是互斥分类；“孩子喜欢”也不是一个可保证的固定配方。`卡梅拉`在本课先作为待样图确认的童趣绘本偏好，不擅自断言用户一定指某一版本或某位作者，更不把它当标准3D渲染术语。

```text
作品/作者/原网页：
我今天只研究：轮廓 / 明暗 / 色彩 / 光线 / 细节（选一个）
第一眼看到哪里，证据是什么：
我提取的一条规则：
我自己的变式主题：
固定哪些条件，只改变哪一项：
变化后哪里更好/更差：
公开使用状态：仅原站观看 / 已获许可 / 自己原创 / 待确认
```

不要用下载几十张图片代替练习。B10让你隐藏参考后换题材，D01再把观察转成基底改造。图片教材的真正制作阶段，再为每课选最少必要图并核对允许的使用方式。
