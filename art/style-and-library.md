# 快速而长期的风格化美术路线

目标不是每件资产都从零建模，也不是把互不搭配的免费模型堆进场景。建议先定义风格，再找许可和结构合适的基底，做少量高收益改造，建立统一的小套件。以下是课程设计与操作计划，本轮还没有制作这些资产成品。

## 1. 一页风格卡

```text
主题：温暖、童趣的森林邮局（示例，可换）
观察距离/相机：固定游戏机位，主要看中远景
形状：大形圆润，少量清楚转折
比例：主建筑略夸张，门窗尺度有一致规则
色彩：受控暖色盘；重要目标与邻近背景有明暗差
光照：柔和主光，暗部可读；不全场自发光
表面：大色块为主，少量手绘感或纹理，避免密集噪声
不要：写实毛孔、复杂脏污、每处都闪亮、满场高对比
保留：玩家能读出路径和交互对象
来源：参考作品原链接；不要直接复制角色和独特图案
```

风格卡是可修改的设计决定，不是对某艺术家或儿童偏好的事实判断。每轮改卡后用一件样本验收，不立即全库批量重做。

## 2. 选择基底，先做四个判断

能否按目的使用和修改；源文件是否可编辑；尺度/原点/拓扑是否够用；离目标风格还有多少差距。把修复成本与更换成本比较。复杂绑定坏资产不要求硬修，换一个更接近目标的资源可能更合理。

## 3. 三轮改造，只做可见收益

**第一轮大形：** 看剪影与游戏大小，调比例、间隙和连接位置。先不画木纹和铆钉。

**第二轮结构：** 检查厚度、开口、支点、拼接与实际用途；平滑/倒角只为解决观察到的问题。

**第三轮表面：** 统一色盘、材质、有限边缘高光和细节密度。固定机位/光照A/B，再看游戏距离。看不到或不服务玩法的细节先停。

始终保留基底只读副本和修改版本。不要把绑定角色的变换按静态道具的处理方式一键Apply；具体资产流程须另核对。

## 4. 六件资产先形成闭环

示例套件：墙、门、窗、树、石头、灯。完成一件合格主资产，再从颜色、比例或少量结构做变体。缩略图用于浏览，不能替代源文件；游戏包装保留功能，源视觉资源可重新导入。

每件最少记录：

```text
asset_id / 名称 / 版本：
用途与目标风格：
作者与原链接 / 取得日期 / 许可原文位置：
游戏使用、修改、公开源文件再分发：分别确认
原始来源文件 / 可编辑主文件 / 交换文件：
尺寸单位 / 原点 / 前向 / 连接规则：
材质数 / 纹理尺寸 / 共享或独立范围：
预览机位 / 已测软件与版本：
验证：未测 / 导入通过 / 功能通过 / 视觉通过（分别记录）
已知限制 / 回退版本：
```

数量少可以先用目录加MD，无须数据库或服务器。大文件、预览、导出缓存的管理等到真实资产规模出现再决定，不提前引入复杂工具。

## 5. 从素材变成资产库的验收

能找得到，知道怎么用，修改范围清楚，能重导入，坏了可恢复，来源可追溯。文件叫final_final_new不提供这些信息。资源库价值来自可靠性和一致性，不来自模型总数。

## 6. 动作复用单独处理

先核对角色骨架、参考姿态、根位移和许可，再试一段，必要时少量裁剪/调速/过渡。动作表现、命中判定、反馈事件各有职责；武打片段只是其中一层。见D05/D06，不强迫美术基础课程承担完整动画专业训练。

## 7. 能力优先级

必须会：观察与描述、对照选择、少量常用参数、影响范围、资产质量与来源验收。知道入口即可：资产浏览器、简单UV、修改器、动作编辑面板。按需查：复杂绑定、重拓扑、手绘贴图全流程、Shader数学、动捕清理。新的真实需求出现后，再升级具体子能力为M。
